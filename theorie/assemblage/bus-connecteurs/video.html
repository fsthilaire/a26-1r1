Port vidéo

Les ports vidéo servent à connecter un moniteur à l'ordinateur. Il existe plusieurs types de ports.

Ce port est généralement une sortie du côté ordinateur et une entrée du côté moniteur.

Il est possible d'avoir des ports d'entrée vidéo sur un ordinateur. Ce port d'entrée permet de faire de l'acquisition vidéo.

Les images des ports vidéo de cette page ont été générées par l'intelligence artificielle Copilot.

1. HDMI​

Il utilise un signal numérique pour transmettre l’image.

Le port a été utilisé au début pour les téléviseurs. Par la suite, c'est devenu un port pour les ordinateurs.

Il existe également une version mini et micro.

2. DisplayPort (DP)​

Il est souvent nommé DP. Il utilise un signal numérique pour transmettre l’image.

Certains moniteurs ont ce port pour faire une connexion DisplayPort à DisplayPort, mais c’est plus rare.

Il existe de nombreux adaptateurs pour transformer le DisplayPort en un autre port vidéo. Le DisplayPort donne une plus grande flexibilité à l'ordinateur.

Il existe également une version mini DisplayPort.

3. DVI​

C’est un port hybride. Il utilise un signal numérique ou analogique pour transmettre l’image.

Il existe plusieurs adaptateurs pour le convertir en HDMI ou en VGA.

Ce port est de moins en moins présent. Il a été remplacé par le HDMI On le retrouve encore sur les moniteurs plus âgés, mais encore dans leur durée de vie utile.

Son connecteur est souvent blanc.

4. VGA​

Il utilise un signal analogique pour transmettre l’image.

Il est utilisé depuis plus de 30 ans. Il est encore présent sur plusieurs cartes.

Son connecteur est souvent bleu.

5. USB-C - Alt mode​

Le port USB type C doit être également Alt mode pour être en mesure d'être utilisé directement comme un port vidéo de la carte graphique interne de l'ordinateur.

Si le port n’a pas la fonctionnalité Alt mode, il ne fonctionnera pas comme un port vidéo, mais comme un port USB normal. Il est possible de connecter une carte graphique externe USB à un port USB normal, sans Alt mode.

Il peut avoir le logo du DisplayPort (image de gauche) ou thunderbolt (image de droite) pour indiquer que le port supporte le Alt mode, mais ce n'est pas toujours le cas. Il faut valider dans le manuel de l’utilisateur.
