Unité de mesure

1. Bit​

Pour conserver de l'information au niveau électronique, il existe 2 états. Il y a une charge électrique ou une polarité magnétique, soit qu'il n'y en a pas.

Ces 2 états sont représentés par un bit qui peut avoir comme valeur 0 ou 1.

2. Octet​

En informatique, la capacité se mesure en octet ou en byte en anglais. Un octet consiste à un regroupement de 8 bits.

Il y a beaucoup de confusion entre bit et byte.

Pour être en mesure de travailler avec de grands nombres, l'utilisation de préfixes permet d'appliquer un facteur de multiplication.

Il existe 2 systèmes de mesure.

L'abréviation pour désigner la taille d'un fichier est importante. Elle permet de déterminer si c'est le facteur 1000 (SI) ou le facteur 1024 (IEC). En notation (IEC), il y a un i après le multiplicateur.

Voici le tableau pour le système (SI).

Le facteur de multiplication est de 1024 par niveau pour le système (IEC). Donc 1 Mio est 1 * 1024 * 1024 = 1 048 576 octets. Le 1024 provient de 2^10^.

Important - Windows

Windows n'utilise pas correctement les symboles pour les unités de mesure. Il utilise un facteur de 1024, mais utilise la notation SI. Il devrait utiliser la notation (IEC).

Une clé USB de 16 Go aura une capacité de 14,9 Go sous Windows.

Windows devrait afficher 14.9 Gio.

Important - Mémoire vive

La mémoire vive n'utilise pas correctement les symboles pour les unités de mesure. Il utilise un facteur de 1024, mais utilise la notation SI. Elle devrait utiliser la notation (IEC).

Une barrette de mémoire vive qui est indiquée à 16 Go aura une capacité réelle de 17,17 Go ou 16 Gio.

Il faudrait inscrire sur la barrette 16 Gio.

3. bps et o/s​

Pour calculer une vitesse de transmission, il existe 2 unités de mesure.

Le bps est pour bit par seconde. C'est donc le nombre de 0 ou de 1 qui se transfère pour 1 seconde.

Le o/s est pour octet par seconde. C'est donc le nombre de regroupements de 8 bits qui se transfère pour une seconde. En anglais, c'est B/s ou MBps. Le B majuscule est pour Byte.

Il est possible de faire la conversion de l'un vers l'autre avec l'équation ci-dessous.

o/s = bps / 8
bps = o/s * 8

Une connexion internet de 60 Mbps ou 60 000 000 bps est l'équivalent de 7.5 Mo/s ou 7 500 000 o/s.

60 Mbps / 8 = 7.5 Mo/s
