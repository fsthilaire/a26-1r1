Accélérateur

L'invite de commandes Windows permet l'utilisation de plusieurs accélérateurs.

1. Auto-complétion - TAB​

La touche TAB permet de suggérer le nom d’un dossier ou d’un fichier dans le dossier en cours.

Pour passer à la suggestion suivante, il suffit de faire TAB de nouveau.

Il est possible d’inscrire les premières lettres et la suggestion en tiendra compte.

Exemple, vous êtes dans le dossier C:\Windows. Il faut aller dans le sous-dossier System32.

C:\Windows> cd sys

Si vous appuyez sur TAB, la première suggestion sera System.

C:\Windows> cd System

Si vous appuyez sur TAB de nouveau, la deuxième suggestion sera System32.

C:\Windows> cd System32

2. Historique des commandes - Flèche Haut, Bas, Droite​

La flèche Haut du clavier permet de réécrire la dernière commande inscrite dans le Shell.

Pour aller plus loin dans l’historique, il suffit d’appuyer sur la flèche haut de nouveau.

La flèche bas du clavier permet de revenir à la commande suivante dans l’historique.

La flèche droite du clavier permet d'écrire la dernière commande caractère par caractère.

La touche ALT+F7 permet d’effacer l’historique des commandes.

3. Navigation sur une ligne - CTRL + Flèche Gauche/Droite, Début/Fin​

La touche CTRL+Gauche permet de déplacer le curseur au début du mot précédent.

La touche CTRL+Droite permet de déplacer le curseur au début du mot suivant.

La touche Début permet de déplacer le curseur au début de la ligne de commande.

La touche Fin permet de déplacer le curseur à la fin de la ligne de commande.

4. Navigation dans l'écran - CTRL + Flèche Haut/Bas​

La touche CTRL+HAUT permet de défiler l’écran vers le haut ligne par ligne.

La touche CTRL+BAS permet de défiler l’écran vers le bas ligne par ligne.

5. Effacement - CTRL + Retour arrière et Échap​

La touche CTRL+Retour arrière (Backspace) permet d’effacer complètement le mot précédent.

La touche Échap ou Esc efface la ligne complètement.
