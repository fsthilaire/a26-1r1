Linux Mint

1. Explication​

Linux Mint est une distribution Linux développée à partir d'Ubuntu, elle-même basée sur Debian.

C'est une distribution très populaire, reconnue pour sa simplicité. Son interface ressemble à celle de Windows, ce qui la rend facile à adopter pour les nouveaux utilisateurs de Linux.

Les versions principales de Linux Mint sont basées sur les versions LTS d'Ubuntu. Elles bénéficient d'un soutien de cinq ans. Il n'y a donc pas de version intermédiaire non LTS à surveiller comme avec Ubuntu.

La dernière version majeure est Linux Mint 22.3 (nom de code Zena). Elle est basée sur Ubuntu 24.04 et bénéficie d'un soutien jusqu'en avril 2029.

Linux Mint ne propose pas d'édition Server officielle. La distribution est principalement destinée à une utilisation sur poste de travail. Elle est offerte en trois éditions avec une interface graphique :

  • Cinnamon
    • Édition principale, moderne et complète
    • Développée principalement par l'équipe de Linux Mint
  • MATE
    • Interface traditionnelle, qui reprend l'approche de GNOME 2
    • Généralement plus légère que Cinnamon
  • Xfce
    • Interface la plus légère des trois éditions
    • Idéale pour les ordinateurs plus anciens ou disposant de peu de mémoire vive

Il existe aussi LMDE (Linux Mint Debian Edition). Cette version est basée directement sur Debian plutôt que sur Ubuntu. La version actuelle est LMDE 7 (nom de code Gigi), basée sur Debian 13.

Un autre avantage de Linux Mint est qu'il peut être utilisé en tant que Live OS ou être installé sur l'ordinateur. La session Live permet d'utiliser le système sans l'installer. Elle donne accès à un environnement Linux complet, et non à un environnement de récupération limité comme Windows PE. En règle générale, les modifications effectuées dans une session Live ne sont toutefois pas conservées après le redémarrage.

Linux Mint propose notamment une prise en charge de Flatpak et plusieurs outils d'administration faciles à utiliser. Les codecs multimédias peuvent être installés pendant l'installation si l'utilisateur sélectionne l'option correspondante; ils peuvent également être ajoutés par la suite.

5. Installation de programmes​

Comme les autres distributions Linux, Linux Mint utilise des dépôts logiciels en ligne pour installer des logiciels.

Il est possible d'installer certains logiciels manuellement à partir de fichiers téléchargés, par exemple des fichiers .deb ou des applications AppImage. Toutefois, il est généralement plus simple d'utiliser les outils de gestion des logiciels.

Linux Mint propose principalement trois façons d'installer des logiciels ou d'accéder aux applications :

  • Gestionnaire de logiciels (Software Manager)
    • Interface graphique permettant de rechercher et d'installer des applications
    • Donne notamment accès aux paquets APT et aux applications Flatpak
  • Flatpak
    • Système de distribution et d'installation d'applications
    • Peut être utilisé en ligne de commande ou à partir d'une interface graphique
    • Les applications sont souvent obtenues à partir du dépôt Flathub
  • APT
    • Gestionnaire de paquets utilisé en ligne de commande
    • Installe des logiciels à partir des dépôts configurés dans le système

À retenir : le Gestionnaire de logiciels est une interface graphique. APT et Flatpak sont des mécanismes de gestion et d'installation de logiciels; ce ne sont pas trois dépôts distincts.

remarque

Contrairement à Ubuntu, Snap est bloqué par défaut dans Linux Mint, mais il est possible de configurer le système pour l'utiliser. Flatpak est pris en charge par défaut et constitue une autre façon d'installer des applications.
