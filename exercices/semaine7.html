Semaine 7 - Cours théorique - Lecteurs, métacaractères, redirection et variables d'environnement

Vous travaillez au service TI de InfoPlus, une petite entreprise fictive de services informatiques. Vous préparez le poste d'un étudiant : vos documents et vos projets se trouvent sur le disque C:, vous avez une clé USB (le lecteur A:) et un disque de sauvegarde (le lecteur B:). Le dossier de départ se trouve dans C:\Exercices-S7\. Vous devez y naviguer, copier des fichiers d'un lecteur à l'autre, créer des fichiers avec l'invite de commandes et utiliser les variables d'environnement de Windows.

À la fin de l'exercice, vous serez capable de :

  • changer de lecteur avec A: et cd /d, et comprendre que chaque lecteur garde son propre dossier courant ;
  • créer des dossiers dans les lecteurs, puis copier et déplacer des fichiers d'un lecteur à l'autre, avec et sans métacaractères ;
  • utiliser les métacaractères * et ? avec dir, copy, move, ren, del et xcopy ;
  • afficher un message avec echo, afficher un fichier avec type et utiliser la redirection >, >> et < ;
  • utiliser les variables d'environnement (%SystemDrive%, %windir%, %temp%, %path%, %date%, %time% et %userprofile%) ;
  • choisir entre un chemin absolu et un chemin relatif selon la situation.
attention

Sécurité. Toutes les commandes de cet exercice visent uniquement les dossiers de C:\Exercices-S7\ (dont les lecteurs A: et B: sont des raccourcis) et un dossier temporaire 1r1\ créé par vous dans le dossier %temp%. Le dossier de Windows n'est utilisé qu'en lecture. Les métacaractères agissent sur plusieurs fichiers à la fois : vérifiez toujours avec dir ce que la commande va toucher avant de supprimer, et relisez la commande avant d'appuyer sur Entrée.

1.3. Comment lire les questions​

Chaque question commence par l'invite qui indique l'endroit où vous devez vous trouver, y compris le lecteur. Les ____ représentent la commande que vous devez écrire.

A:\Travaux> ____

Un chemin qui désigne un dossier se termine toujours par \, pour le distinguer d'un fichier. Par exemple, Documents\ est un dossier et notes.txt est un fichier. Les symboles . et .. font exception.

Dans les questions, le symbole .\ placé devant un nom désigne le dossier courant. Par exemple, .\notes.txt est le fichier notes.txt qui se trouve dans le dossier courant.

Les réponses ajoutent toujours le \ à la fin du dossier, mais il n'est pas obligatoire pour faire fonctionner la commande.

Chaque question demande une seule action. Pour certaines questions, il peut être plus facile d'utiliser plusieurs commandes. La réponse va afficher les deux options.

1.4. Ouvrir l'invite de commandes​

  1. Ouvrez le menu d'exécution. + R.

  2. Inscrivez cmd et appuyez sur la touche ENTRÉE.

 

1.5. Créer les lecteurs A: et B:​

Pour cet exercice, vous créez deux lecteurs virtuels avec la commande subst. Chaque lecteur est un raccourci vers un dossier : le lecteur A: représente une clé USB et le lecteur B: représente un disque de sauvegarde. Vous masquez ensuite le dossier _Lecteurs\ avec la commande attrib, pour que les deux « disques » n'apparaissent plus dans l'arborescence de C:.

subst A: C:\Exercices-S7\_Lecteurs\A
subst B: C:\Exercices-S7\_Lecteurs\B
attrib +h C:\Exercices-S7\_Lecteurs

À retenir :

  • utilisez une invite de commandes normale (pas une invite administrateur) : les lecteurs créés ne sont pas visibles dans l'autre type d'invite ;
  • les fichiers du lecteur A: sont les mêmes que ceux du dossier C:\Exercices-S7\_Lecteurs\A\, et ceux du lecteur B: sont les mêmes que ceux de C:\Exercices-S7\_Lecteurs\B\ ;
  • la commande attrib +h ajoute l'attribut « masqué » : le dossier _Lecteurs\ n'apparaît plus dans les résultats de dir, mais il existe toujours et les lecteurs A: et B: continuent de fonctionner ;
  • pour la commande attrib, on écrit le nom du dossier sans le \ final ;
  • pour rendre le dossier visible de nouveau, on utilise attrib -h C:\Exercices-S7\_Lecteurs ;
  • les lecteurs disparaissent quand l'ordinateur redémarre : il faut alors refaire les commandes subst ;
  • à la fin de l'exercice, vous supprimerez les lecteurs avec subst A: /d et subst B: /d.

2.3. Les nouvelles notions​

  • Les lecteurs. Pour changer de lecteur, on écrit la lettre du lecteur suivie de : (par exemple A:). Chaque lecteur garde en mémoire son propre dossier courant : quand on revient sur un lecteur, on retrouve le dossier où l'on se trouvait.
  • cd et les lecteurs. La commande cd seule ne change pas de lecteur : elle change seulement le dossier courant du lecteur indiqué. L'option /d change le lecteur et le dossier.
  • La racine d'un lecteur. À la racine d'un lecteur (par exemple A:\), il n'y a pas de dossier parent : les lignes . et .. ne sont pas affichées.
  • Les métacaractères. Le caractère * remplace n'importe quel nombre de caractères : *.txt désigne tous les fichiers qui se terminent par .txt, et notes.* désigne tous les fichiers qui s'appellent notes, peu importe l'extension. Le caractère ? remplace exactement un caractère : rapport-0?.txt désigne rapport-01.txt, rapport-02.txt, etc.
  • echo et type. La commande echo affiche un message. La commande type affiche le contenu d'un fichier.
  • La redirection. Le symbole > envoie le résultat d'une commande dans un fichier : si le fichier existe, son contenu est remplacé. Le symbole >> ajoute le résultat à la fin du fichier. Le symbole < fait l'inverse : il envoie le contenu d'un fichier à une commande. Par exemple, find "Reseaux" < liste.txt affiche seulement les lignes du fichier liste.txt qui contiennent le mot Reseaux. Aucun message n'est affiché à l'écran quand le résultat est envoyé dans un fichier.
  • Les variables d'environnement. Une variable d'environnement est un nom entouré de % que Windows remplace par sa valeur. Exemple : %SystemDrive% est remplacé par C:. Pour afficher la valeur d'une variable, on utilise echo.

Question 31​

Affichez la valeur de la variable d'environnement %path% avec la commande echo.

  • a) Quel caractère sépare les dossiers dans le résultat ?
C:\Exercices-S7\Projets\Jeu> ____
Réponse

La commande est : echo %path%

a) Le caractère ; (point-virgule).

La commande echo affiche le texte qui la suit, et Windows remplace %path% par sa valeur. Le résultat est une liste de dossiers séparés par des points-virgules : ce sont les dossiers où Windows cherche les programmes quand on écrit un nom de commande. Le résultat varie d'un ordinateur à l'autre.

Question 32​

Écrivez le texte La date est : suivi de la date du jour, avec la variable %date%, dans le fichier A:\Archive\info-date.txt, en notation absolue.

C:\Exercices-S7\Projets\Jeu> ____
Réponse

La commande est : echo La date est : %date% > A:\Archive\info-date.txt

Windows remplace %date% par la date du jour. Le symbole > envoie le résultat de echo dans le fichier : aucun message n'apparaît à l'écran. Si le fichier existe déjà, son contenu est remplacé.

Question 33​

Ajoutez à la fin du fichier A:\Archive\info-date.txt le texte L'heure est suivi de l'heure actuelle, avec la variable %time%, en notation absolue.

C:\Exercices-S7\Projets\Jeu> ____
Réponse

La commande est : echo L'heure est %time% >> A:\Archive\info-date.txt

Le symbole >> ajoute le résultat à la fin du fichier, sans effacer ce qu'il contient déjà.

Question 34​

Affichez le contenu du fichier A:\Archive\info-date.txt, en notation absolue.

  • a) Combien de lignes le fichier contient-il ?
C:\Exercices-S7\Projets\Jeu> ____
Réponse

La commande est : type A:\Archive\info-date.txt

a) 2 lignes : la date, puis l'heure.

Question 35​

Le fichier A:\Personnel\liste.txt contient une liste de cours. Affichez seulement les lignes qui contiennent le mot Reseaux, avec la commande find et le symbole <, en notation absolue.

  • a) Combien de lignes sont affichées ?
C:\Exercices-S7\Projets\Jeu> ____
Réponse

La commande est : find /n "Reseaux" < A:\Personnel\liste.txt

a) 2 lignes : Reseaux (ligne 2) et Reseaux avances (ligne 5).

Le symbole < envoie le contenu du fichier liste.txt à la commande find. L'option /n ajoute le numéro de la ligne, entre crochets, devant chaque résultat.

Question 36​

Affichez la valeur de la variable d'environnement %SystemDrive%.

C:\Exercices-S7\Projets\Jeu> ____
Réponse

La commande est : echo %SystemDrive%

Le résultat est C: : le lecteur sur lequel Windows est installé.

Question 37​

Déplacez-vous dans le dossier C:\Exercices-S7\Documents\, en utilisant la variable %SystemDrive% à la place de C:.

C:\Exercices-S7\Projets\Jeu> ____
Réponse

La commande est : cd %SystemDrive%\Exercices-S7\Documents\

Windows remplace %SystemDrive% par C: avant d'exécuter la commande.

Question 38​

Affichez la valeur de la variable d'environnement %windir%.

C:\Exercices-S7\Documents> ____
Réponse

La commande est : echo %windir%

Le résultat est C:\Windows : le dossier de Windows.

Question 39​

Affichez la valeur de la variable d'environnement %temp%.

C:\Exercices-S7\Documents> ____
Réponse

La commande est : echo %temp%

Le résultat ressemble à C:\Users\VotreNom\AppData\Local\Temp : le dossier des fichiers temporaires (le nom de l'utilisateur change d'un ordinateur à l'autre).

Question 40​

Affichez tous les fichiers .dll du dossier de Windows, C:\Windows\, en utilisant la variable %windir% et le métacaractère *.

  • a) Les fichiers affichés ont-ils tous l'extension .dll ?
C:\Exercices-S7\Documents> ____
Réponse

La commande est : dir %windir%\*.dll

a) Oui : le métacaractère * sélectionne seulement les fichiers qui se terminent par .dll.

La commande affiche seulement les fichiers de ce dossier, pas ceux de ses sous-dossiers. Le nombre de fichiers affichés dépend de la version de Windows. Ici, on ne fait que lire le contenu du dossier.

Question 41​

Créez le dossier 1r1 dans le dossier des fichiers temporaires, avec la variable %temp%.

C:\Exercices-S7\Documents> ____
Réponse

La commande est : md %temp%\1r1\

Windows remplace %temp% par le chemin du dossier des fichiers temporaires. Le dossier 1r1\ est créé à l'intérieur. La commande md n'affiche rien quand elle réussit.

Question 42​

Affichez tous les fichiers .ini du dossier de Windows, C:\Windows\, et envoyez le résultat dans le fichier redini.txt du dossier 1r1\ des fichiers temporaires, avec les variables %windir% et %temp%, le métacaractère * et la redirection >.

C:\Exercices-S7\Documents> ____
Réponse

La commande est : dir %windir%\*.ini > %temp%\1r1\redini.txt

Le symbole > envoie le résultat de dir dans le fichier redini.txt du dossier 1r1\ : aucun message n'apparaît à l'écran.

Les variables %windir% et %temp% sont remplacées par leur valeur, et le métacaractère * sélectionne tous les fichiers .ini.

Question 43​

Affichez le contenu du fichier redini.txt du dossier 1r1\ des fichiers temporaires, avec la variable %temp%.

  • a) Le fichier win.ini apparaît-il dans la liste ?
  • b) Les fichiers listés ont-ils tous l'extension .ini ?
C:\Exercices-S7\Documents> ____
Réponse

La commande est : type %temp%\1r1\redini.txt

a) Oui : le fichier win.ini fait partie de la liste. b) Oui.

Le fichier contient tout le résultat de la commande dir : les lignes d'en-tête, la liste des fichiers et le total.

La commande affiche seulement les fichiers de ce dossier, pas ceux de ses sous-dossiers. Le nombre de fichiers affichés dépend de la version de Windows. Ici, on ne fait que lire le contenu du dossier.

Question 44​

Copiez le fichier A:\Archive\info-date.txt dans le dossier 1r1\ des fichiers temporaires, avec la variable %temp%.

C:\Exercices-S7\Documents> ____
Réponse

La commande est : copy A:\Archive\info-date.txt %temp%\1r1\

Windows remplace %temp% par le chemin du dossier des fichiers temporaires. La destination est un dossier (elle se termine par \) : le fichier garde son nom.

Question 45​

Affichez le contenu du dossier 1r1\ des fichiers temporaires, avec la variable %temp%.

  • a) Combien de fichiers y a-t-il dans ce dossier ?
  • b) Combien de sous-dossiers ?
C:\Exercices-S7\Documents> ____
Réponse

La commande est : dir %temp%\1r1\

a) 2 fichiers : info-date.txt et redini.txt. b) 0 sous-dossier.

6. Partie 4 — Faire le ménage​

Question 46​

Supprimez le fichier info-date.txt que vous avez copié à la question 44, dans le dossier 1r1\ des fichiers temporaires, avec la variable %temp%.

C:\Exercices-S7\Documents> ____
Réponse

La commande est : del %temp%\1r1\info-date.txt

On supprime seulement les fichiers que l'on a créés : on ne touche jamais aux autres fichiers du dossier %temp%.

Question 47​

Supprimez le dossier 1r1\ des fichiers temporaires et son contenu (il contient encore le fichier redini.txt), avec la variable %temp%. Windows vous demandera une confirmation : répondez O.

C:\Exercices-S7\Documents> ____
Réponse

La commande est : rd /s %temp%\1r1\

Windows demande « Êtes-vous sûr (O/N) ? ». Tapez O puis Entrée.

Le dossier contenait encore redini.txt : rd seul aurait refusé de le supprimer, mais rd /s supprime le dossier et tout son contenu. On ne supprime que ce que l'on a créé : on ne touche jamais aux autres fichiers du dossier %temp%.

Question 48​

Supprimez le dossier vide A:\Travaux\, en notation absolue.

C:\Exercices-S7\Documents> ____
Réponse

La commande est : rd A:\Travaux\

Le dossier est vide : rd fonctionne.

Question 49​

Supprimez le fichier A:\Archive\info-date.txt, en notation absolue.

C:\Exercices-S7\Documents> ____
Réponse

La commande est : del A:\Archive\info-date.txt

Supprimez le lecteur virtuel A:.

C:\Exercices-S7\Documents> ____

La commande est : subst A: /d

Seul le raccourci est supprimé : les fichiers du dossier C:\Exercices-S7\_Lecteurs\A\ sont toujours là.

Supprimez le lecteur virtuel B:.

a) Rien n'est affiché : il ne reste aucun lecteur virtuel.

Question 53​

Pour pouvoir supprimer le dossier C:\Exercices-S7\, allez directement à la racine du lecteur C:\ en utilisant le symbole de la racine.

C:\Exercices-S7\Documents> ____
Réponse

La commande est : cd \

Peu importe la profondeur où l'on se trouve, cd \ ramène à la racine en une seule commande. Ici, elle remplace deux commandes cd ...

Question 54​

Supprimez le dossier C:\Exercices-S7\ et tout son contenu, en notation absolue. Windows vous demandera une confirmation : répondez O.

C:\> ____
Réponse

La commande est : rd /s C:\Exercices-S7\

Windows demande « Êtes-vous sûr (O/N) ? ». Tapez O puis Entrée.

Cette fois, vous n'êtes plus dans le dossier : la suppression réussit.

Question 55​

Retournez à votre dossier utilisateur, C:\Users\VotreNom\, en utilisant la variable %userprofile%.

C:\> ____
Réponse

La commande est : cd %userprofile%

Windows remplace %userprofile% par le chemin de votre dossier personnel : vous êtes revenu à l'endroit de départ. L'exercice est terminé.
