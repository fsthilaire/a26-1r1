Exercices supplémentaires, invite de commande #1

Vous reprenez tout ce que vous avez appris sur l'invite de commandes : navigation, création et suppression de dossiers et de fichiers, copie, déplacement, renommage, métacaractères et redirection. Le dossier de départ se trouve dans C:\exec-cmd1\.

À la fin de l'exercice, vous aurez révisé :

  • la navigation avec cd, en notation absolue et relative ;
  • la création et la suppression de dossiers et de fichiers (md, rd, del) ;
  • la copie, le déplacement et le renommage de fichiers (copy, move, ren) ;
  • les métacaractères * et ? ;
  • la redirection > et >>, et l'affichage d'un fichier avec type ;
  • l'arborescence avec tree.
attention

Sécurité. Toutes les commandes de cet exercice visent uniquement le dossier C:\exec-cmd1\. Relisez toujours une commande de suppression avant d'appuyer sur Entrée : del et rd ne passent pas par la corbeille.

1. Explication​

1.1. Extraction du fichier​

1- Téléchargez le fichier exec-cmd1.zip

2- Effectuez l'extraction à la racine du lecteur C:\.

1.2. Arborescence de départ​

Seuls les dossiers sont affichés.

C:\exec-cmd1\
├── ex1
│   └── lib
└── wc1

1.3. Comment lire les questions​

Chaque question commence par l'invite qui indique l'endroit où vous devez vous trouver. Les ____ représentent la commande que vous devez écrire.

Un chemin qui désigne un dossier se termine toujours par \. Chaque question demande une seule action, sauf quand plusieurs commandes sont nécessaires pour construire un résultat (créer un fichier avec echo, par exemple). Pour les questions où plusieurs commandes sont possibles, la réponse affiche les deux options.

1.4. Ouvrir l'invite de commandes​

  1. Ouvrez le menu d'exécution. + R.

  2. Inscrivez cmd et appuyez sur la touche ENTRÉE.

 

2. Rappels​

2.1 Chemin absolu et chemin relatif​

Chemin absoluChemin relatif
Commence parLa lettre du lecteur (C:\, A:\, B:\)Un nom de dossier ou ..
Dépend du dossier courant ?Non, il fonctionne de partoutOui, il part du dossier affiché dans l'invite
ExempleA:\Travaux\Travaux\

Trois symboles à retenir :

  • . désigne le dossier courant ;
  • .. désigne le dossier parent (celui qui contient le dossier courant) ;
  • \ seul, au début d'un chemin, désigne la racine du lecteur (par exemple C:\).

2.2. Aide-mémoire des commandes​

3. Partie 1 — Commandes de base​

Débutez les exercices dans le dossier C:\exec-cmd1\.

Question 1​

Changez le dossier de travail pour C:\exec-cmd1\ex1\, en notation relative.

C:\exec-cmd1> ____
Réponse

La commande est : cd ex1

Question 2​

Affichez le contenu du dossier courant.

C:\exec-cmd1\ex1> ____
Réponse

La commande est : dir

1 dossier, 7 fichiers, un peu plus loin le détail des tailles.

Question 3​

En vous basant sur le résultat de la commande précédente, répondez aux questions suivantes.

  • a) Combien de dossiers y a-t-il (sans compter . et ..) ?
  • b) Combien de fichiers ?
  • c) Quelle est la taille totale des fichiers ?
  • d) Quel est le fichier le plus gros ?
C:\exec-cmd1\ex1> ____
Réponse

La commande à refaire est : dir

a) 1 dossier. b) 7 fichiers. c) 8 739 octets (sans compter le dossier lib\). d) note.exe avec 4 000 octets.

On ne compte ni ., ni .., ni les sous-dossiers dans la taille totale.

Question 4​

Créez le dossier C:\exec-cmd1\rep1\, en notation absolue.

C:\exec-cmd1\ex1> ____
Réponse

La commande est : md C:\exec-cmd1\rep1\

Aucun message : la commande a réussi.

Question 5​

Créez le dossier C:\exec-cmd1\rep1\reps1\, en notation absolue.

C:\exec-cmd1\ex1> ____
Réponse

La commande est : md C:\exec-cmd1\rep1\reps1\

Aucun message : la commande a réussi.

Question 6​

Copiez le fichier C:\exec-cmd1\ex1\lib\mdba.lib dans le dossier C:\exec-cmd1\rep1\reps1\, en notation absolue.

C:\exec-cmd1\ex1> ____
Réponse

La commande est : copy C:\exec-cmd1\ex1\lib\mdba.lib C:\exec-cmd1\rep1\reps1\

La destination est un dossier (elle se termine par \) : le fichier garde son nom.

Question 7​

Changez le dossier de travail pour C:\exec-cmd1\ex1\lib\, en notation absolue.

C:\exec-cmd1\ex1> ____
Réponse

La commande est : cd C:\exec-cmd1\ex1\lib\

Question 8​

Déplacez le fichier C:\exec-cmd1\ex1\lib\mdbb.lib dans le dossier C:\exec-cmd1\rep1\reps1\. Utilisez la notation relative pour la source et la notation absolue pour la destination.

C:\exec-cmd1\ex1\lib> ____
Réponse

La commande est : move mdbb.lib C:\exec-cmd1\rep1\reps1\

Windows indique le nombre de fichiers déplacés. Le fichier n'existe plus dans ex1\lib\.

Question 9​

Changez le dossier de travail pour C:\exec-cmd1\rep1\reps1\, en notation relative.

  • En une seule commande
  • En plusieurs commandes
C:\exec-cmd1\ex1\lib> ____
Réponse

En une commande : cd ..\..\rep1\reps1\

En quatre commandes : cd .., cd .., cd rep1, puis cd reps1

Question 10​

Renommez le fichier C:\exec-cmd1\rep1\reps1\mdbb.lib en zmdbb.lis, en notation relative.

C:\exec-cmd1\rep1\reps1> ____
Réponse

La commande est : ren mdbb.lib zmdbb.lis

Aucun message : la commande a réussi.

Question 11​

Supprimez le fichier C:\exec-cmd1\rep1\reps1\mdba.lib, en notation relative.

C:\exec-cmd1\rep1\reps1> ____
Réponse

La commande est : del mdba.lib

Aucun message : la commande a réussi.

Question 12​

Créez le dossier C:\exec-cmd1\rep1\reps2\, en notation absolue.

C:\exec-cmd1\rep1\reps1> ____
Réponse

La commande est : md C:\exec-cmd1\rep1\reps2\

Aucun message : la commande a réussi.

Question 13​

Changez le dossier de travail pour C:\exec-cmd1\rep1\reps2\, en notation relative.

  • En une seule commande
  • En plusieurs commandes
C:\exec-cmd1\rep1\reps1> ____
Réponse

En une commande : cd ..\reps2

En deux commandes : cd .., puis cd reps2

Question 14​

Supprimez le dossier C:\exec-cmd1\rep1\reps2\. Est-ce que ça fonctionne ? Que devez-vous faire pour réussir ?

C:\exec-cmd1\rep1\reps2> ____
Réponse

Si vous êtes dans C:\exec-cmd1\rep1\reps2\, la commande rd C:\exec-cmd1\rep1\reps2\ échoue : on ne peut pas supprimer le dossier dans lequel on se trouve.

Il faut changer de dossier courant : cd .., puis rd C:\exec-cmd1\rep1\reps2\.

Question 15​

Créez le dossier C:\exec-cmd1\xdoc\, en notation absolue.

C:\exec-cmd1\rep1> ____
Réponse

La commande est : md C:\exec-cmd1\xdoc\

Aucun message : la commande a réussi.

Question 16​

Créez le dossier C:\exec-cmd1\redirect\, en notation absolue.

C:\exec-cmd1\rep1> ____
Réponse

La commande est : md C:\exec-cmd1\redirect\

Aucun message : la commande a réussi.

Question 17​

Supprimez le fichier C:\exec-cmd1\ex1\database.dll, en notation absolue.

C:\exec-cmd1\rep1> ____
Réponse

La commande est : del C:\exec-cmd1\ex1\database.dll

Aucun message : la commande a réussi.

Question 18​

Changez le dossier de travail pour C:\exec-cmd1\ex1\, en notation relative.

  • En une seule commande
  • En plusieurs commandes
C:\exec-cmd1\rep1> ____
Réponse

En une commande : cd ..\ex1

En deux commandes : cd .., puis cd ex1

Question 19​

Supprimez le fichier C:\exec-cmd1\ex1\typo64.dll, en notation relative.

C:\exec-cmd1\ex1> ____
Réponse

La commande est : del typo64.dll

Aucun message : la commande a réussi.

Question 20​

Changez le dossier de travail pour C:\exec-cmd1\, en notation relative.

C:\exec-cmd1\ex1> ____
Réponse

La commande est : cd ..

Question 21​

Créez l'arborescence suivante avec le moins de commandes md possible (c'est possible en 4 commandes), en notation relative.

C:\exec-cmd1\
├── s1
│   └── s2
│       ├── s31
│       └── s32
└── tx1
    ├── tx21
    └── tx22
C:\exec-cmd1> ____
Réponse

Quatre commandes, une par dossier de dernier niveau :

md s1\s2\s31

md s1\s2\s32

md tx1\tx21

md tx1\tx22

La commande md crée aussi les dossiers intermédiaires : s1\ et s2\ sont créés par la première commande, tx1\ par la troisième.

Question 22​

Créez le fichier C:\exec-cmd1\fruits.txt. Il doit contenir uniquement ce message, sur 3 lignes : Pomme, Banane, Orange.

C:\exec-cmd1> ____
Réponse

Trois commandes :

echo Pomme > C:\exec-cmd1\fruits.txt

echo Banane >> C:\exec-cmd1\fruits.txt

echo Orange >> C:\exec-cmd1\fruits.txt

La première commande utilise > : elle crée le fichier (ou efface son contenu s'il existait déjà). Les deux suivantes utilisent >>, pour ajouter une ligne sans effacer les précédentes.

Question 23​

Supprimez le dossier C:\exec-cmd1\s1\ et tout son contenu, en notation absolue. Windows vous demandera une confirmation : répondez O.

C:\exec-cmd1> ____
Réponse

La commande est : rd /S C:\exec-cmd1\s1\

Windows demande « Êtes-vous sûr (O/N) ? ». Tapez O puis Entrée.

4. Partie 2 — Les métacaractères​

Question 24​

Changez le dossier de travail pour C:\exec-cmd1\wc1\, en notation absolue.

C:\exec-cmd1> ____
Réponse

La commande est : cd C:\exec-cmd1\wc1\

Question 25​

Affichez tous les fichiers qui ont l'extension .txt.

C:\exec-cmd1\wc1> ____
Réponse

La commande est : dir *.txt

Il y a 24 fichiers.

Question 26​

Affichez tous les fichiers qui débutent par doc.

C:\exec-cmd1\wc1> ____
Réponse

La commande est : dir doc*

Il y a 5 fichiers.

Question 27​

Affichez les 10 fichiers hdoc20.txt à hdoc29.txt, avec le métacaractère ?. Les fichiers hdoc200.txt à hdoc202.txt ne doivent pas s'afficher.

C:\exec-cmd1\wc1> ____
Réponse

La commande est : dir hdoc2?.txt

Il y a 10 fichiers : hdoc20.txt à hdoc29.txt.

? remplace exactement un caractère : hdoc200.txt n'apparaît pas, car il y a trois caractères après hdoc2 (0, 0 et rien avant le point n'y correspond pas à un seul ?).

Question 28​

Copiez tous les fichiers .txt dans le dossier C:\exec-cmd1\txt\. Faites d'abord un dir avec le métacaractère pour vérifier combien de fichiers seront copiés : si la copie échoue, faites l'action manquante.

C:\exec-cmd1\wc1> ____
Réponse

Le dossier txt\ n'existe pas encore : il faut d'abord le créer.

md C:\exec-cmd1\txt\

puis

copy *.txt C:\exec-cmd1\txt\*.txt

24 fichiers sont copiés.

Question 29​

Déplacez tous les fichiers qui débutent par adoc ou hdoc dans le dossier C:\exec-cmd1\xdoc\, avec le métacaractère ? et en une seule commande. Les fichiers qui débutent par doc (sans lettre avant) ne doivent pas être déplacés.

C:\exec-cmd1\wc1> ____
Réponse

La commande est : move ?doc* C:\exec-cmd1\xdoc\

14 fichiers sont déplacés : tous ceux qui commencent par un caractère, suivi de doc (donc adoc* et hdoc*, mais pas doc*).

Question 30​

Renommez tous les fichiers qui ont l'extension .zxt par l'extension .bob.

C:\exec-cmd1\wc1> ____
Réponse

La commande est : ren *.zxt *.bob

Aucun message : la commande a réussi.

5. Partie 3 — Redirection​

Question 31​

Affichez le contenu du dossier courant et enregistrez le résultat dans le fichier C:\exec-cmd1\redirect\ex31.txt, en notation absolue pour le fichier.

C:\exec-cmd1\wc1> ____
Réponse

La commande est : dir > C:\exec-cmd1\redirect\ex31.txt

Aucun message : la commande a réussi. Aucun résultat ne s'affiche : tout est envoyé dans le fichier. Le dossier wc1\ contient 13 éléments à ce stade.

Question 32​

Changez le dossier de travail pour C:\exec-cmd1\.

C:\exec-cmd1\wc1> ____
Réponse

La commande est : cd ..

Question 33​

Affichez l'arborescence du dossier C:\exec-cmd1\ avec les fichiers, et enregistrez le résultat dans le fichier C:\exec-cmd1\redirect\ex33.txt.

C:\exec-cmd1> ____
Réponse

La commande est : tree /F > C:\exec-cmd1\redirect\ex33.txt

L'option /f (ou /F) ajoute les fichiers à l'arborescence, qui autrement n'affiche que les dossiers. Le symbole > envoie le résultat dans le fichier.

Question 34​

Affichez le contenu des 2 fichiers du dossier C:\exec-cmd1\redirect\.

C:\exec-cmd1> ____
Réponse

Deux commandes :

type C:\exec-cmd1\redirect\ex31.txt

puis

type C:\exec-cmd1\redirect\ex33.txt

Chaque fichier contient le résultat qui avait été redirigé dedans, comme si la commande d'origine s'était affichée à l'écran.

6. Partie 4 — Faire le ménage​

Question 35​

Retournez à la racine du lecteur C:\, en notation absolue.

C:\exec-cmd1> ____
Réponse

La commande est : cd C:\

Question 36​

Supprimez le dossier C:\exec-cmd1\ et tout son contenu, en notation absolue. Windows vous demandera une confirmation : répondez O.

C:\> ____
Réponse

La commande est : rd /S C:\exec-cmd1\

Windows demande « Êtes-vous sûr (O/N) ? ». Tapez O puis Entrée.

L'exercice est terminé : le dossier C:\exec-cmd1\ et tout son contenu ont été supprimés.
