Exercices supplémentaires, invite de commande #2

Vous reprenez et approfondissez tout ce que vous avez appris sur l'invite de commandes : navigation, création et suppression de dossiers et de fichiers, copie, déplacement, renommage, métacaractères et redirection. Le dossier de départ se trouve dans C:\exec-cmd2\.

À la fin de l'exercice, vous aurez révisé :

  • la navigation avec cd, en notation absolue et relative, incluant le changement de lecteur ;
  • la création et la suppression de dossiers et de fichiers (md, rd, del) ;
  • la copie, le déplacement et le renommage de fichiers, incluant avec des métacaractères (copy, move, ren) ;
  • les métacaractères * et ? ;
  • la redirection > et >>, et l'affichage d'un fichier avec type ;
  • l'arborescence avec tree.
attention

Sécurité. Toutes les commandes de cet exercice visent uniquement le dossier C:\exec-cmd2\. Relisez toujours une commande de suppression avant d'appuyer sur Entrée : del et rd ne passent pas par la corbeille.

1. Explication​

1.1. Extraction du fichier​

1- Téléchargez le fichier exec-cmd2.zip

2- Effectuez l'extraction à la racine du lecteur C:\.

1.2. Arborescence de départ​

Seuls les dossiers sont affichés.

C:\exec-cmd2\
├── cours
│   ├── data
│   │   └── lib
│   └── info.txt
└── zsrc            (= lecteur Z:)
    └── wc2

1.3. Comment lire les questions​

Chaque question commence par l'invite qui indique l'endroit où vous devez vous trouver. Les ____ représentent la commande que vous devez écrire.

Un chemin qui désigne un dossier se termine toujours par \. Chaque question demande une seule action, sauf quand plusieurs commandes sont nécessaires pour construire un résultat.

1.4. Ouvrir l'invite de commandes​

  1. Ouvrez le menu d'exécution. + R.

  2. Inscrivez cmd et appuyez sur la touche ENTRÉE.

 

1.5. Créer le lecteur Z:​

Pour cet exercice, vous créez deux lecteurs virtuels avec la commande subst. Chaque lecteur est un raccourci vers un dossier : le lecteur A: représente une clé USB et le lecteur B: représente un disque de sauvegarde. Vous masquez ensuite le dossier _Lecteurs\ avec la commande attrib, pour que les deux « disques » n'apparaissent plus dans l'arborescence de C:.

subst Z: C:\exec-cmd2\zsrc\
attrib +h C:\exec-cmd2\zsrc

À retenir :

  • utilisez une invite de commandes normale (pas une invite administrateur) : les lecteurs créés ne sont pas visibles dans l'autre type d'invite ;
  • les fichiers du lecteur Z: sont les mêmes que ceux du dossier C:\exec-cmd2\zsrc\;
  • la commande attrib +h ajoute l'attribut « masqué » : le dossier C:\exec-cmd2\zsrc\ n'apparaît plus dans les résultats de dir, mais il existe toujours et le lecteur Z:continue de fonctionner ;
  • pour la commande attrib, on écrit le nom du dossier sans le \ final ;
  • pour rendre le dossier visible de nouveau, on utilise attrib -h C:\exec-cmd2\zsrc\ ;
  • les lecteurs disparaissent quand l'ordinateur redémarre : il faut alors refaire les commandes subst ;
  • à la fin de l'exercice, vous supprimerez les lecteurs avec subst Z: /d.

2. Rappels​

2.1 Chemin absolu et chemin relatif​

Chemin absoluChemin relatif
Commence parLa lettre du lecteur (C:\, A:\, B:\)Un nom de dossier ou ..
Dépend du dossier courant ?Non, il fonctionne de partoutOui, il part du dossier affiché dans l'invite
ExempleA:\Travaux\Travaux\

Trois symboles à retenir :

  • . désigne le dossier courant ;
  • .. désigne le dossier parent (celui qui contient le dossier courant) ;
  • \ seul, au début d'un chemin, désigne la racine du lecteur (par exemple C:\).

2.2. Aide-mémoire des commandes​

3. Partie 1 — Commandes de base​

Débutez les exercices dans le dossier C:\exec-cmd2\.

Question 1​

Changez le dossier de travail pour C:\exec-cmd2\cours\, en notation absolue.

C:\exec-cmd2> ____
Réponse

La commande est : cd c:\exec-cmd2\cours

Question 2​

Affichez le contenu du dossier courant.

C:\exec-cmd2\cours> ____
Réponse

La commande est : dir

L'élément data est un dossier.

L'élément info.txt est un fichier.

Question 3​

Le dossier C:\exec-cmd2\cours\ affiche un dossier et un fichier. Changez le dossier de travail pour vous déplacer dans le sous-dossier. Il ne faut pas tenir compte des dossiers . et ...

C:\exec-cmd2\cours> ____
Réponse

La commande est : cd data

Question 4​

Les questions suivantes se font en analysant le contenu du dossier C:\exec-cmd2\cours\data\ : a) Combien de dossiers y a-t-il (sans compter . et ..) ? b) Combien de fichiers ? c) Quelle est la taille totale des fichiers ? d) Quel est le fichier le plus gros ?

C:\exec-cmd2\cours\data> ____
Réponse

La commande à exécuter est : dir

a) 1 dossier. b) 7 fichiers. c) 10250 octets (sans compter le dossier lib\). d) note.exe avec 4200 octets.

On ne compte ni ., ni .., ni les sous-dossiers dans la taille totale.

Question 5​

Changez le dossier de travail pour C:\exec-cmd2\cours\, en notation relative.

C:\exec-cmd2\cours\data> ____
Réponse

La commande est : cd ..

Question 6​

Créez le dossier C:\exec-cmd2\copie\, en notation relative.

C:\exec-cmd2\cours> ____
Réponse

La commande est : md ..\copie

Aucun message : la commande a réussi.

Question 7​

Changez le dossier de travail pour le lecteur Z:.

C:\exec-cmd2\cours> ____
Réponse

La commande est : z:

Question 8​

Copiez tous les fichiers du dossier Z:\ dans le dossier C:\exec-cmd2\copie\. Utilisez la notation relative pour la source et la notation absolue pour la destination.

Z:\> ____
Réponse

La commande est : copy *.* C:\exec-cmd2\copie\

Question 9​

Changez le dossier de travail pour C:\exec-cmd2\copie\, en notation absolue, en utilisant 2 commandes.

Z:\> ____
Réponse

La commande #1 est : c:

La commande #2 est : cd c:\exec-cmd2\copie

Il est possible de le faire en une seule commande : cd /d c:\exec-cmd2\copie

Question 10​

Changez le dossier de travail pour C:\exec-cmd2\cours\data\, en notation relative.

C:\exec-cmd2\copie> ____
Réponse

La commande est : cd ..\cours\data

Question 11​

Affichez tous les fichiers qui ont l'extension .dll.

C:\exec-cmd2\cours\data> ____
Réponse

La commande est : dir *.dll

Question 12​

Déplacez tous les fichiers qui ont l'extension .htm du dossier C:\exec-cmd2\cours\data\ vers le dossier C:\exec-cmd2\cours\data\html\. Utilisez 2 commandes : la première pour créer le dossier (notation relative), la deuxième pour le déplacement (notation relative pour la source, notation absolue pour la destination).

C:\exec-cmd2\cours\data> ____
Réponse

La commande #1 est : md html

La commande #2 est : move *.htm C:\exec-cmd2\cours\data\html\

Question 13​

Affichez le contenu du dossier C:\exec-cmd2\cours\data\html\ sans vous déplacer dans ce dossier, pour voir son contenu initial. Utilisez la notation absolue.

Réponse

La commande est : dir c:\exec-cmd2\cours\data\html

Notez que les fichiers ont l'extension .htm.

Question 14​

Renommez tous les fichiers du dossier C:\exec-cmd2\cours\data\html\ qui ont l'extension .htm pour l'extension .html. Utilisez la notation absolue.

C:\exec-cmd2\cours\data> ____
Réponse

La commande est : ren c:\exec-cmd2\cours\data\html\*.htm *.html

Question 15​

Réponse

La commande est : dir c:\exec-cmd2\cours\data\html

Notez que les fichiers ont maintenant l'extension .html.

Question 16​

Renommez le dossier C:\exec-cmd2\cours\data\lib\ pour librairie. Utilisez la notation relative.

C:\exec-cmd2\cours\data> ____

La commande est : ren lib librairie

Question 19​

Créez une copie de tous les fichiers .lib pour avoir l'extension .lib.old. Exemple : le fichier mdba.lib doit avoir une copie mdba.lib.old. Utilisez la notation relative pour la source et la destination.

C:\exec-cmd2\cours\data\librairie> ____

Affichez de nouveau le contenu du dossier courant.

La commande est : dir

Question 23​

Créez le dossier C:\exec-cmd2\cours\backup\, en notation absolue.

C:\exec-cmd2\cours\data> ____
Réponse

La commande est : md c:\exec-cmd2\cours\backup

Question 24​

Créez une copie de tous les fichiers directs du dossier C:\exec-cmd2\cours\data\ dans le dossier C:\exec-cmd2\cours\backup\, en ajoutant .copy à la fin de leur nom. Exemple : le fichier database.dll doit avoir une copie database.dll.copy. Utilisez la notation relative pour la source et la notation absolue pour la destination. (Les sous-dossiers html\ et librairie\ ne sont pas concernés.)

C:\exec-cmd2\cours\data> ____
Réponse

La commande est : copy *.* c:\exec-cmd2\cours\backup\*.*.copy

Question 25​

Affichez le contenu du dossier C:\exec-cmd2\cours\backup\ sans vous déplacer, pour voir le résultat. Utilisez la notation absolue.

C:\exec-cmd2\cours\data> ____
Réponse

La commande est : dir c:\exec-cmd2\cours\backup

Question 26​

Supprimez le dossier C:\exec-cmd2\cours\data\librairie\. Utilisez la notation relative. Le dossier contient des fichiers : il faut utiliser un paramètre additionnel pour permettre la suppression.

C:\exec-cmd2\cours\data> ____
Réponse

La commande est : rd librairie /s

Le paramètre /s permet de supprimer le contenu du dossier également.

Question 27​

Supprimez tous les fichiers du dossier C:\exec-cmd2\cours\data\html\. Le dossier lui-même ne doit pas être supprimé. Utilisez la notation absolue.

C:\exec-cmd2\cours\data> ____
Réponse

La commande est : del c:\exec-cmd2\cours\data\html\*.*

Question 28​

Affichez le contenu du dossier C:\exec-cmd2\cours\data\html\ sans vous déplacer, pour voir le changement. Utilisez la notation absolue.

C:\exec-cmd2\cours\data> ____
Réponse

La commande est : dir c:\exec-cmd2\cours\data\html

Question 29​

Créez l'arborescence ci-dessous avec le moins de commandes md possible (c'est possible en 4 commandes), en notation absolue.

C:\exec-cmd2\
├── d1
│   └── d12
│       ├── d131
│       └── d132
└── docs
    ├── txt
    └── word
C:\exec-cmd2\cours\data> ____
Réponse

La commande #1 est : md c:\exec-cmd2\d1\d12\d131

La commande #2 est : md c:\exec-cmd2\d1\d12\d132

La commande #3 est : md c:\exec-cmd2\docs\txt

La commande #4 est : md c:\exec-cmd2\docs\word

La commande md crée aussi les dossiers intermédiaires : d1\ et d1\d12\ sont créés par la première commande, docs\ par la troisième.

4. Partie 2 — Les métacaractères​

Question 22​

Changez le dossier de travail pour Z:\wc2\, en notation absolue et en changeant de lecteur en une seule commande.

C:\exec-cmd2\cours\data> ____
Réponse

La commande est : cd /d z:\wc2\

Question 31​

Affichez tous les fichiers qui ont l'extension .txt.

Z:\wc2> ____
Réponse

La commande est : dir *.txt

Il y a 28 fichiers.

Question 32​

Affichez tous les fichiers dont le nom débute par doc.

Z:\wc2> ____
Réponse

La commande est : dir doc*.*

Il y a 8 fichiers.

Le .* est important : il permet de restreindre la recherche à la partie nom seulement.

Question 33​

Affichez les 10 fichiers de hdoc20.txt à hdoc29.txt. Les fichiers hdoc200.txt et hdoc201.txt ne doivent pas s'afficher.

Z:\wc2> ____
Réponse

La commande est : dir hdoc2?.txt

Il y a 10 fichiers.

Le ? remplace exactement un caractère : hdoc200.txt a deux caractères après hdoc2 avant l'extension, il ne correspond donc pas.

Question 34​

Affichez tous les fichiers qui débutent par un caractère suivi de doc (comme adoc* ou hdoc*). Les fichiers qui débutent par doc (sans lettre avant) ne doivent pas être affichés.

Z:\wc2> ____
Réponse

La commande est : dir ?doc*.*

Il y a 16 fichiers.

Si un fichier s'appelait zdoc12.txt, il serait tout de même affiché : le ? représente n'importe quel caractère.

Question 35​

Affichez tous les fichiers qui contiennent le chiffre 3 dans leur nom.

Z:\wc2> ____
Réponse

La commande est : dir *3*.*

Il y a 9 fichiers.

Question 36​

Affichez tous les fichiers dont le nom se termine par le chiffre 8, sans tenir compte de leur extension.

Z:\wc2> ____
Réponse

La commande est : dir *8.*

Il y a 7 fichiers.

Question 37​

Affichez tous les fichiers dont le nom a une longueur de 6 caractères et qui se termine par 2.

Z:\wc2> ____
Réponse

La commande est : dir ?????2.*

Il y a 5 fichiers.

5. Partie 3 — Redirection​

Question 30​

Changez le dossier de travail pour C:\exec-cmd2\cours\, en notation absolue et en changeant de lecteur en une seule commande.

Z:\wc2> ____
Réponse

La commande est : cd /d c:\exec-cmd2\cours\

Question 31​

Affichez tous les fichiers .dll du dossier C:\Windows\System32\ (la commande pour cet affichage est dir c:\windows\system32\*.dll), et redirigez le résultat dans le fichier C:\exec-cmd2\redirect\num1.txt. Si le fichier existe déjà, il doit être écrasé.

N'oubliez pas de créer le dossier C:\exec-cmd2\redirect\ au préalable.

C:\exec-cmd2\cours> ____
Réponse

La commande est : dir c:\Windows\System32\*.dll > c:\exec-cmd2\redirect\num1.txt

Aucun résultat ne s'affiche : tout est envoyé dans le fichier.

Tapez notepad c:\exec-cmd2\redirect\num1.txt pour voir le contenu du fichier dans le Bloc-notes.

Question 32​

Affichez l'arborescence du dossier C:\exec-cmd2\cours\ sans les fichiers (la commande est tree c:\exec-cmd2\cours), puis avec les fichiers (la commande est tree /F c:\exec-cmd2\cours). Redirigez les résultats des 2 commandes dans le même fichier C:\exec-cmd2\redirect\num2.txt.

C:\exec-cmd2\cours> ____
Réponse

La commande #1 est : tree c:\exec-cmd2\cours >> c:\exec-cmd2\redirect\num2.txt

La commande #2 est : tree /F c:\exec-cmd2\cours >> c:\exec-cmd2\redirect\num2.txt

Les deux commandes utilisent >> (et non >) pour que le résultat de la deuxième s'ajoute à celui de la première, au lieu de l'effacer.

Tapez type c:\exec-cmd2\redirect\num2.txt pour voir le contenu du fichier dans l'invite de commande.

Question 33​

Vous devez écraser le fichier C:\exec-cmd2\redirect\num2.txt pour y inscrire le texte ci-dessous, avec 2 commandes echo.

Je maitrise bien les redirections.
Le cours 1R1 est palpitant !
C:\exec-cmd2\cours> ____
Réponse

La commande #1 est : echo Je maitrise bien les redirections. > c:\exec-cmd2\redirect\num2.txt

La commande #2 est : echo Le cours 1R1 est palpitant ! >> c:\exec-cmd2\redirect\num2.txt

Il est important d'utiliser un seul > pour la première commande, pour effacer le contenu du fichier. La deuxième commande doit avoir >> pour conserver le contenu de la première.

Tapez type c:\exec-cmd2\redirect\num2.txt pour voir le contenu du fichier dans l'invite de commande.

6. Partie 4 — Faire le ménage​

Question 34​

Retournez à la racine du lecteur C:\, en notation absolue.

C:\exec-cmd2\cours> ____
Réponse

La commande est : cd C:\

Question 35​

Supprimez le dossier C:\exec-cmd2\ et tout son contenu, en notation absolue. Windows vous demandera une confirmation : répondez O.

C:\> ____
Réponse

La commande est : rd /S C:\exec-cmd2\

Windows demande « Êtes-vous sûr (O/N) ? ». Tapez O puis Entrée.

Question 36​

Retirez le lecteur temporaire Z: que vous avez créé en préparation. L'exercice est maintenant terminé.

C:\> ____
Réponse

La commande est : subst Z: /d

Le lecteur Z: n'apparaît plus dans l'explorateur de fichiers. L'exercice est terminé : le dossier C:\exec-cmd2\ et tout son contenu ont été supprimés.
