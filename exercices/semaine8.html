Exercice de la semaine 8 - Cours théorique - Création d'une clé USB démarrable avec Rufus

Dans cet exercice, vous allez apprendre à utiliser l'utilitaire Rufus pour créer une clé USB démarrable pour le programme d'installation de Windows 11.

Avertissement

L'ordinateur du laboratoire n'a pas accès à Internet.

Utilisez votre portable pour accéder aux notes de cours.

1. Préparation​

1.1. Disque SSD​

1- Éteignez l'ordinateur s'il est en cours de démarrage.

2- Insérez le disque Samsung 250 Go Format 2.5" dans le boitier convertisseur 2.5" à 3.5".

3- Insérez le boitier convertisseur dans le tiroir SATA.

1.2. Configuration du BIOS​

Pour les ordinateurs du laboratoire 1204, nous devons faire des manipulations dans le BIOS. Il est possible que le BIOS soit correctement configuré et qu'aucune modification ne soit nécessaire.

1- Appuyez sur la touche F2 pour accéder au BIOS, lors du démarrage de l'ordinateur.

2- Appuyez sur le bouton Unlock.

3- Inscrivez le mot de passe dans la zone Password et appuyez sur le bouton OK. Le mot de passe vous sera donné en classe pour des raisons de sécurité.

4- Dans le menu System Configuration -> Drive, il faut cocher uniquement le SATA-3. Les autres éléments doivent être décochés.

5- Dans le menu Secure Boot -> Secure Boot Enable, il faut décocher Secure Boot Enable.

6- Appuyez sur le bouton Apply pour enregistrer les modifications. Le bouton reste grisé s'il n'y a eu aucune modification.

7- Redémarrez l'ordinateur.

1.3. Ventoy​

Dans le menu Ventoy, veuillez utiliser le fichier correspondant à votre groupe. L'enseignant vous l'indiquera en classe.

1.4. Utilisateur Windows​

Veuillez utiliser l'utilisateur Etu1R1. Le mot de passe vous sera donné en classe.

2. Créer la clé USB​

Veuillez vous référer à la section Procédures -> Utilitaires -> Rufus pour avoir la procédure de création.

Vous devez créer une clé démarrable pour Windows 11.

attention

Branchez la clé USB dans un port USB 3 pour avoir le maximum de vitesse.

Le processus prend plusieurs minutes, il faut avoir le maximum de vitesse.

Voici le chemin de l'exécutable de Rufus : c:\apps\rufus\rufus-4.15p.exe

Voici le chemin pour le fichier ISO de Windows 11 25H2 : c:\iso\Win11_25H2_A26.iso

3. Tester la clé USB​

1- Redémarrez l'ordinateur.

2- Appuyez sur la touche F12 pour accéder au menu de démarrage du BIOS.

3- Sélectionnez la clé USB. Vous devez inscrire le mot de passe du BIOS.

4- Vous devriez voir la fenêtre du programme d'installation. Le chargement du logiciel peut prendre environ deux minutes.

4. Installer Windows​

Veuillez vous référer à la section Procédures -> Installation de système d'exploitation -> Windows 11 pour avoir la procédure d'installation.

Installez Windows sur le disque Samsung qui se retrouve dans le tiroir SATA.

Voici les paramètres pour l'installation.

  • Windows doit être installé sur une partition de 120 Go (Windows). Effectuez la conversion en Mo (Windows) correctement en utilisant le facteur 1024.

    • Le disque n'est pas vide, il faudra effacer les partitions existantes. Référez-vous à la section 6.2. Disque interne non vide pour effacer le disque correctement.

  • Vous devez installer l'édition Famille.

  • Le nom d'utilisateur doit être Etudiant et il ne doit pas avoir de mot de passe.

  • La disposition du clavier doit être Français (Canada).

5. Créer une partition​

Lorsque Windows sera installé, créez des partitions sur l'espace restant du disque Samsung.

Veuillez vous référer à la section Procédures -> Windows -> Gestion du disque pour avoir les procédures.

Ces notions vous seront présentées la semaine prochaine, mais essayez de faire les actions.

  • Partition 1

    • Taille : 52 Go (Effectuez la conversion avec le facteur 1024 pour avoir le nombre en Mo => 52 * 1024 = 53 248 Mo)
    • Système de fichiers : NTFS
    • Nom de la partition : DATA
    • Lettre du lecteur : Y

  • Partition 2

    • Taille : 15 Go (Effectuez la conversion avec le facteur 1024 pour avoir le nombre en Mo)
    • Système de fichiers : FAT32
    • Nom de la partition : UNIVERSEL
    • Lettre du lecteur : X

  • Partition 3

    • Taille : Espace restant

    • Système de fichiers : exFAT

    • Nom de la partition : Aucune (Laissez la zone de texte vide.)

    • Lettre du lecteur : W
