Semaine 6 - Cours théorique - Copier, déplacer, renommer et rechercher des fichiers en invite de commandes

Vous travaillez au service TI de InfoPlus, une petite entreprise fictive de services informatiques. Le dossier de départ contient les dossiers de ses clients, des modèles de documents et des rapports. Il se trouve dans C:\Exercices-S6\. Vous devez le parcourir, y chercher des fichiers, créer un espace de sauvegardes, puis réorganiser les fichiers uniquement avec l'invite de commandes.

À la fin de l'exercice, vous serez capable de :

  • afficher uniquement les dossiers (dir /ad), uniquement les fichiers (dir /a-d) ou une liste étendue (dir /w) ;
  • chercher un fichier précis avec dir, dans un seul dossier ou dans toute une arborescence (dir /s) ;
  • créer une arborescence de dossiers avec le moins de commandes md possible et l'afficher avec tree ;
  • copier un fichier avec copy, le déplacer avec move et le renommer avec ren, y compris en changeant son nom pendant la copie ou le déplacement ;
  • copier un dossier et son contenu avec xcopy ;
  • vous déplacer dans l'arborescence avec cd ;
  • choisir entre un chemin absolu et un chemin relatif selon la situation.
attention

Sécurité. Toutes les commandes de cet exercice visent uniquement le dossier C:\Exercices-S6\. Relisez toujours une commande avant d'appuyer sur Entrée : move, ren et les commandes de suppression modifient vos fichiers, et la suppression ne passe pas par la corbeille.

1.3. Comment lire les questions​

Chaque question commence par l'invite qui indique l'endroit où vous devez vous trouver. Les ____ représentent la commande que vous devez écrire.

C:\Exercices-S6> ____

Un chemin qui désigne un dossier se termine toujours par \, pour le distinguer d'un fichier. Par exemple, Clients\ est un dossier et notes.txt est un fichier. Les symboles . et .. font exception.

Dans les questions, le symbole .\ placé devant un nom désigne le dossier courant. Par exemple, .\notes.txt est le fichier notes.txt qui se trouve dans le dossier courant.

Les réponses ajoutent toujours le \ à la fin du dossier, mais il n'est pas obligatoire pour faire fonctionner la commande.

Chaque question demande une seule action, sauf la question de création d'arborescence avec md, qui demande plusieurs commandes. Pour certaines questions, il peut être plus facile d'utiliser plusieurs commandes. La réponse va afficher les deux options.

1.4. Ouvrir l'invite de commandes​

  1. Ouvrez le menu d'exécution. + R.

  2. Inscrivez cmd et appuyez sur la touche ENTRÉE.

2.3. Les nouvelles commandes​

  • dir /ad affiche seulement les dossiers. Les lignes . et .. sont incluses.
  • dir /a-d affiche seulement les fichiers.
  • dir /w affiche la liste étendue : seulement les noms, sur plusieurs colonnes. Les dossiers sont entre crochets [ ].
  • dir nom cherche un fichier précis dans un seul dossier. Si le fichier n'existe pas, Windows affiche « Fichier introuvable ».
  • dir /s nom cherche un fichier précis dans le dossier indiqué et dans tous ses sous-dossiers. Chaque dossier qui contient le fichier est affiché.
  • tree dossier affiche l'arborescence des dossiers sous forme d'arbre. Sans option, seuls les dossiers sont affichés (l'option /f ajoute les fichiers).
  • md crée aussi les dossiers intermédiaires qui n'existent pas. Par exemple, md Archives\2026\Garage\ crée Archives\, 2026\ et Garage\ en une seule commande.
  • copy source destination copie un fichier. Le fichier d'origine reste à sa place.
  • move source destination déplace un fichier. Le fichier d'origine n'existe plus à sa place.
  • copy et move : si la destination est un dossier (terminé par \), le fichier garde son nom. Si la destination se termine par un nom de fichier, le fichier reçoit ce nouveau nom. Exemple : copy notes.txt Archives\notes.txt.bck.
  • ren ancien nouveau renomme un fichier. Le deuxième argument est seulement le nouveau nom, sans chemin.
  • xcopy source destination /e /i copie un dossier et tout son contenu. L'option /e inclut les sous-dossiers. L'option /i indique que la destination est un dossier (sans elle, Windows peut poser une question). Si le dossier de destination n'existe pas, il est créé.

5. Partie 3 — Créer une arborescence avec md​

Question 15​

Le dossier C:\Exercices-S6\Sauvegardes\ n'existe pas encore. Créez l'arborescence suivante avec le moins de commandes md possible, en notation absolue.

C:\Exercices-S6\Sauvegardes\
├── 2026
│   ├── Boulangerie
│   │   ├── Factures
│   │   └── Ordinateurs
│   └── Garage
│       └── Factures
└── 2025
    └── Librairie
        └── Ordinateurs
C:\Exercices-S6\Clients> ____
Réponse

Quatre commandes (une par dossier de dernier niveau) :

md C:\Exercices-S6\Sauvegardes\2026\Boulangerie\Factures\

md C:\Exercices-S6\Sauvegardes\2026\Boulangerie\Ordinateurs\

md C:\Exercices-S6\Sauvegardes\2026\Garage\Factures\

md C:\Exercices-S6\Sauvegardes\2025\Librairie\Ordinateurs\

La commande md crée aussi les dossiers intermédiaires qui n'existent pas. Par exemple, la première commande crée à la fois Sauvegardes\, 2026\, Boulangerie\ et Factures\.

Sans cette propriété, il faudrait dix commandes : une pour chacun des dix dossiers de l'arborescence.

Remarque : md accepte aussi plusieurs chemins dans une même commande, par exemple md Factures\ Ordinateurs\ (crée deux dossiers dans le dossier courant).

Les dossiers sont affichés par ordre alphabétique : 2025\ apparaît donc avant 2026\. Comparez le résultat avec l'arborescence de la question 15 pour vérifier que tout a été créé.

La commande est : dir /s C:\Exercices-S6\Sauvegardes\facture-001.txt.bck

a) 1 fois. b) Dans C:\Exercices-S6\Sauvegardes\2026\Boulangerie\Factures\. c) 418 octets : la copie a la même taille que l'original.

Question 31​

La facture facture-003.txt a été classée par erreur chez la librairie : elle appartient au garage. Déplacez le fichier C:\Exercices-S6\Clients\Librairie\Factures\facture-003.txt dans le dossier C:\Exercices-S6\Clients\Garage\Factures\, en notation absolue.

C:\Exercices-S6\Clients\Boulangerie\Factures> ____
Réponse

La commande est : move C:\Exercices-S6\Clients\Librairie\Factures\facture-003.txt C:\Exercices-S6\Clients\Garage\Factures\

La destination est un dossier : elle se termine par \. Windows affiche le nombre de fichiers déplacés.

Question 32​

Cherchez le fichier facture-003.txt dans C:\Exercices-S6\Clients\ et dans tous ses sous-dossiers, en notation absolue.

  • a) Combien de fichiers facture-003.txt sont trouvés ?
  • b) Dans quel dossier se trouve-t-il maintenant ?
C:\Exercices-S6\Clients\Boulangerie\Factures> ____
Réponse

La commande est : dir /s C:\Exercices-S6\Clients\facture-003.txt

a) 1 fichier. b) Dans C:\Exercices-S6\Clients\Garage\Factures\.

Contrairement à copy, la commande move ne laisse pas de copie à l'ancien emplacement : le fichier n'existe plus dans Librairie\Factures\.

7. Partie 5 — Ajouter un nouveau client​

Question 33​

Remontez dans le dossier C:\Exercices-S6\Clients\, en notation relative.

  • En une seule commande
  • En plusieurs commandes
C:\Exercices-S6\Clients\Boulangerie\Factures> ____
Réponse

En une commande : cd ..\..

En deux commandes : cd .., puis cd ..

Question 34​

Un nouveau client, la papeterie, s'ajoute à la liste. Créez le dossier C:\Exercices-S6\Clients\Papeterie\, en notation relative.

C:\Exercices-S6\Clients> ____
Réponse

La commande est : md Papeterie\

Question 35​

Déplacez-vous dans le dossier C:\Exercices-S6\Clients\Papeterie\, en notation relative.

C:\Exercices-S6\Clients> ____
Réponse

La commande est : cd Papeterie\

Question 36​

Copiez le fichier C:\Exercices-S6\Modeles\contrat-modele.txt dans le dossier courant C:\Exercices-S6\Clients\Papeterie\. Utilisez la notation absolue pour le fichier source et le symbole .\ pour le dossier courant.

C:\Exercices-S6\Clients\Papeterie> ____
Réponse

La commande est : copy C:\Exercices-S6\Modeles\contrat-modele.txt .\

Le symbole .\ désigne le dossier courant, ici C:\Exercices-S6\Clients\Papeterie\. La commande est donc équivalente à copy C:\Exercices-S6\Modeles\contrat-modele.txt C:\Exercices-S6\Clients\Papeterie\.

Le fichier garde son nom, puisque la destination est un dossier.

Question 37​

Affichez uniquement les fichiers du dossier courant.

  • a) Le fichier .\contrat-modele.txt existe-t-il ?
  • b) Combien de fichiers y a-t-il dans ce dossier ?
  • c) Quelle est la taille du fichier ?
C:\Exercices-S6\Clients\Papeterie> ____
Réponse

La commande est : dir /a-d

a) Oui. b) 1 fichier. c) 1 210 octets.

Le fichier d'origine existe toujours dans C:\Exercices-S6\Modeles\ : la commande copy ne supprime pas l'original.

Question 38​

Renommez le fichier C:\Exercices-S6\Clients\Papeterie\contrat-modele.txt en contrat.txt, en notation relative.

C:\Exercices-S6\Clients\Papeterie> ____
Réponse

La commande est : ren contrat-modele.txt contrat.txt

Le deuxième argument est seulement le nouveau nom : il ne contient pas de chemin.

La commande ren n'affiche rien quand elle réussit.

Question 39​

Vérifiez si le fichier C:\Exercices-S6\Clients\Papeterie\contrat-modele.txt existe encore, en notation relative.

  • a) Le fichier existe-t-il encore ?
C:\Exercices-S6\Clients\Papeterie> ____
Réponse

La commande est : dir contrat-modele.txt

a) Non (« Fichier introuvable »). Le fichier a été renommé : il n'existe plus sous son ancien nom.

Question 40​

Renommez le fichier C:\Exercices-S6\Modeles\facture-modele.txt en facture-modele-v2.txt, en notation absolue.

C:\Exercices-S6\Clients\Papeterie> ____
Réponse

La commande est : ren C:\Exercices-S6\Modeles\facture-modele.txt facture-modele-v2.txt

Le premier argument est le chemin absolu du fichier. Le deuxième argument est seulement le nouveau nom, sans chemin.

8. Partie 6 — Copier un dossier avec xcopy​

Question 41​

Revenez en arrière d'un niveau, dans le dossier C:\Exercices-S6\Clients\, en notation relative.

C:\Exercices-S6\Clients\Papeterie> ____
Réponse

La commande est : cd ..

Question 42​

Copiez le dossier C:\Exercices-S6\Clients\Garage\ et tout son contenu dans le dossier C:\Exercices-S6\Sauvegardes\2026\Garage\, en notation relative.

  • a) Combien de fichiers ont été copiés ?
C:\Exercices-S6\Clients> ____
Réponse

La commande est : xcopy Garage\ ..\Sauvegardes\2026\Garage\ /e /i

a) 4 fichiers : contrat.txt, notes.txt, Factures\facture-001.txt et Factures\facture-003.txt (la facture déplacée à la question 31).

Le dossier Sauvegardes\2026\Garage\ existe déjà (avec son sous-dossier Factures\) : xcopy y copie le contenu de Garage\, sous-dossier Factures\ compris grâce à l'option /e.

Question 43​

Copiez le dossier C:\Exercices-S6\Clients\Papeterie\ et tout son contenu dans un nouveau dossier C:\Exercices-S6\Sauvegardes\2026\Papeterie\, en notation absolue.

  • a) Combien de fichiers ont été copiés ?
C:\Exercices-S6\Clients> ____
Réponse

La commande est : xcopy C:\Exercices-S6\Clients\Papeterie\ C:\Exercices-S6\Sauvegardes\2026\Papeterie\ /e /i

a) 1 fichier : contrat.txt.

Le dossier Papeterie\ n'existe pas encore dans Sauvegardes\2026\ : xcopy le crée. L'option /i indique que la destination est un dossier.

Question 44​

Déplacez-vous dans le dossier C:\Exercices-S6\Sauvegardes\2026\, en notation absolue.

C:\Exercices-S6\Clients> ____
Réponse

La commande est : cd C:\Exercices-S6\Sauvegardes\2026\

Question 45​

Affichez uniquement les dossiers du dossier courant.

  • a) Combien de sous-dossiers y a-t-il dans ce dossier ?
  • b) Le dossier .\Papeterie\ existe-t-il ?
C:\Exercices-S6\Sauvegardes\2026> ____
Réponse

La commande est : dir /ad

a) 3 sous-dossiers : Boulangerie\, Garage\ et Papeterie\. b) Oui : il a été créé par la commande xcopy.

Question 46​

Cherchez le fichier contrat.txt dans C:\Exercices-S6\Sauvegardes\2026\ et dans tous ses sous-dossiers, en notation relative.

  • a) Combien de fichiers contrat.txt sont trouvés ?
  • b) Dans quels dossiers ?
C:\Exercices-S6\Sauvegardes\2026> ____
Réponse

La commande est : dir /s contrat.txt

a) 2 fichiers. b) Dans C:\Exercices-S6\Sauvegardes\2026\Garage\ et C:\Exercices-S6\Sauvegardes\2026\Papeterie\.

9. Partie 7 — Faire le ménage​

Question 47​

Pour pouvoir supprimer le dossier C:\Exercices-S6\, sortez de la structure : allez directement à la racine du lecteur C:\ en utilisant le symbole de la racine.

C:\Exercices-S6\Sauvegardes\2026> ____
Réponse

La commande est : cd \

Peu importe la profondeur où l'on se trouve, cd \ ramène à la racine en une seule commande. Ici, elle remplace trois commandes cd ...

Question 48​

Supprimez le dossier C:\Exercices-S6\ et tout son contenu, en notation absolue. Windows vous demandera une confirmation : répondez O.

C:\> ____
Réponse

La commande est : rd /s C:\Exercices-S6\

Windows demande « Êtes-vous sûr (O/N) ? ». Tapez O puis Entrée.

Cette fois, vous n'êtes plus dans le dossier : la suppression réussit et l'exercice est terminé.
