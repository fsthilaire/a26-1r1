Installation du pilote

Lorsque les pilotes n'utilisent pas un programme d'installation, mais des fichiers .inf, il faut les installer manuellement à partir du Gestionnaire de périphériques.

Vous pouvez regrouper les fichiers des pilotes dans le dossier c:\drivers\.

1. Sélection du pilote​

  1. Effectuez un clic-droit sur le périphérique à identifier et sélectionnez Mettre à jour le pilote.

  2. Sélectionnez l'item Parcourir mon ordinateur pour rechercher des pilotes.

  3. Sélectionnez le dossier qui contient le fichier .inf pour la pièce.

  4. Appuyez sur le bouton Suivant.

2. Le pilote fonctionne​

  1. Si le pilote est compatible avec la pièce, vous avez le message Windows a mis à jour vos pilotes. Appuyez sur le bouton Fermer pour terminer.

  2. La pièce ne sera plus dans la section Autres périphériques et elle sera sous sa propre section.

3. Le pilote ne fonctionne pas​

  1. Si vous avez le message ci-dessous, le pilote n'est pas compatible avec la pièce ou avec le système d'exploitation. La 2e option est que le dossier sélectionné à l'étape 3 de la section 1 ne contient pas de fichier .inf.

  2. Vous devez retourner à l'étape 3 de la section 1 pour sélectionner de nouveau le bon dossier ou continuer la recherche du bon pilote sur le site du fournisseur.
