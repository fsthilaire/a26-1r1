Rufus

Rufus est un logiciel qui permet de créer une unité de stockage démarrable avec une seule image.

Il permet d'activer ou de désactiver certaines options de l'outil d'installation de Windows.

La version présentée est la 4.15p (version portable)

Pour plus d'informations, veuillez visiter le site de Rufus.

1. Téléchargement​

Téléchargez la dernière version sur le site de téléchargement de Rufus.

2. Installation​

Il s'agit d'un logiciel portable.

Veuillez extraire le fichier zip dans un dossier.

Le dossier c:\apps\rufus\ est suggéré.

3. Créer une clé démarrable - Configuration de base​

  1. Insérez la clé USB dans l'ordinateur. Il faut une clé USB d'une capacité minimale de 16 Go.

​ :::danger[Important]

​ Le contenu de la clé USB sera effacé.

​ :::

  1. Démarrez le programme rufus4.15p.exe en tant qu'administrateur.

  2. Sélectionnez la clé USB dans la liste déroulante.

  3. Dans le menu Type de démarrage, sélectionnez Image disque ou ISO (Veuillez sélectionner) et appuyez sur le bouton SÉLECTION.

  4. Sélectionnez le fichier ISO que vous désirez copier sur votre clé USB et appuyez sur le bouton Ouvrir.

  5. Appuyez sur le bouton Démarrer.

  1. Dans le cas d'un fichier ISO pour l'installation de Windows 11, il faut cocher les 2 cases ci-dessous.

    Ces options permettent d'installer sur un ordinateur non supporté officiellement par Windows 11 pour faire des tests et des laboratoires. En production, il n'est pas recommandé d'installer Windows 11 sur un ordinateur non officiellement supporté.

  2. Appuyez sur le bouton Oui pour accepter que le contenu de la clé USB soit effacé.

  3. Appuyez sur le bouton OK pour confirmer le 2e avertissement que le contenu de la clé sera effacé.

  4. La création de la clé est en cours d'exécution. La barre de progression doit atteindre 100 %. Le processus peut prendre plusieurs minutes selon la taille du fichier ISO.

4. Utilisation​

Vous devez démarrer l'ordinateur à partir de la clé USB.

  1. Sur les ordinateurs Dell, lors du démarrage de l'ordinateur, la touche F12 permet de choisir l'unité de stockage.

    Avertissement

    Le nom de la clé USB sera différent en fonction du modèle utilisé.

    L'apparence du menu sera différente en fonction de l'ordinateur.
