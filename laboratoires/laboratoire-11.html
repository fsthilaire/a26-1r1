Laboratoire de la semaine 11

Dans ce laboratoire, vous allez faire un récapitulatif sur l'installation de Windows et des pilotes.

1. Démarrage de Windows PE​

1- Insérez le disque Sandisk 256 Go SSD 2.5" dans le tiroir SATA du haut.

2- Insérez la clé USB du laboratoire dans un port USB 3.

3- Démarrez l'ordinateur sur la clé USB.

4- Sélectionnez Win11_1R1_A26.iso dans Ventoy.

Pourquoi le clavier ne répond-il pas ? Le clavier est bien branché et fonctionnel. Il y a quelque chose dans le BIOS.

Indice

C'est dans une section en lien avec les ports USB sous System Configuration.

Je vous donne la réponse dans 5 minutes.

Vous n'avez pas non plus le mot de passe du BIOS.

Consultez le manuel de l'utilisateur pour avoir la procédure. L'information se retrouve sous la section Désactivation d’un mot de passe système (Page 36) ou Disabling a system password (Page 34).

Indice

C'est une manipulation à effectuer sur la carte-mère.

Voici un article Wikipedia (français) qui explique la définition d'un cavalier (jumper). https://fr.wikipedia.org/wiki/Cavalier_(%C3%A9lectronique)

2. Installer Windows 11​

Pour ce modèle d'ordinateur, vous devez prendre la Version précédente de la configuration. Procédures -> Installation de système d'exploitation -> Windows 11 -> Section 1, Étape 3

Voici les paramètres pour l'installation :

  • Édition : Famille

  • Partition d'installation : 82 Go

  • Nom de l'ordinateur : Win11Tb# Remplacez le # par le numéro de table.

  • Nom d'utilisateur : admin1r1

  • Disposition du clavier : Français (Canada)

3. Trouver les fichiers pour les pilotes​

Les pilotes des périphériques de la carte-mère sont disponibles sur la clé USB.

Afin de vous pratiquer pour l'examen théorique, voici quelques exercices pour trouver la partition et trouver le fichier.

3.1. Pilotes de la carte-mère Dell​

3.1.1. Trouver la partition​

Sur la clé USB du laboratoire, vous avez une partition. Utilisez l'utilitaire Gestion des disques.

Voici les indices.

1- La partition a une capacité de 6 Go.

2- La partition utilise un système de fichiers qui permet des fichiers de plus de 4 Go.

3- La partition utilise un système de fichiers qui permet de gérer la sécurité des fichiers dans Windows.

Réponse

Il y a 3 partitions de 6 Go (ZONE1, ZONE2 et ZONE3)

ZONE1 est en FAT32. Ce système de fichiers ne permet pas de gérer de la sécurité et ne permet pas d'avoir des fichiers de plus de 4 Go.

ZONE2 est en NTFS. C'est le système de fichiers de Windows 11. Il est en mesure de gérer la sécurité sur les fichiers et d'avoir des fichiers de plus de 4 Go. Le fichier est dans cette partition.

ZONE3 est en exFAT. Ce système de fichiers ne permet pas de gérer de la sécurité, mais il permet des fichiers de plus de 4 Go.

3.1.2. Trouver le fichier zip​

Le fichier pilotes-dell.zip est caché dans un dossier de la partition identifiée à la section 3.1.1.

À partir de l'invite de commandes, trouvez le fichier.

Réponse

La commande de recherche à partir de la racine de la partition est dir /s pilotes-dell.zip
Le dossier est J:\R4D\X8N\W7E\N3R\Q1M\V2K\
Il est possible que la lettre du lecteur soit différente de J:

3.1.3. Copier le fichier​

Copiez le fichier pilotes-dell.zip dans le dossier c:\drivers\ à partir de l'invite de commandes en utilisant la notation absolue.

Réponse

copy J:\R4D\X8N\W7E\N3R\Q1M\V2K\pilotes-dell.zip c:\drivers\

Il est possible que la lettre du lecteur soit différente de J:

3.1.4. Extraction​

À partir du gestionnaire de fichiers, effectuez l'extraction des fichiers dans le dossier c:\drivers\pilotes-dell\.

3.2. Pilotes des périphériques PCI et PCIe​

3.2.1. Trouver la partition​

Sur la clé USB du laboratoire, vous avez une partition. Utilisez l'utilitaire Gestion des disques.

Voici les indices.

1- La partition a une capacité de 2 Go.

2- La partition utilise un système de fichiers qui est considéré comme celui qui est universel.

Réponse

Il y a 3 partitions de 2 Go (PART1, PART2 et PART3)

PART1 est en FAT32. Ce système de fichiers est considéré comme « universel ». Le fichier est dans cette partition.

PART2 est en NTFS. C'est le système de fichiers de Windows 11.

PART3 est en exFAT. C'est l'évolution du FAT32 pour permettre des partitions de plus de 32 Go, mais il est moins « universel » que le FAT32.

3.2.2. Trouver le fichier zip​

Le fichier pilotes-pci-pcie.zip est caché dans un dossier de la partition identifiée à la section 3.2.1.

À partir de l'invite de commandes, trouvez le fichier.

Réponse

La commande de recherche à partir de la racine de la partition est dir /s pilotes-pci-pcie.zip
Le dossier est : F:\B9T\K5W\H2L\D8U\F7H\L4P<br /> Il est possible que la lettre du lecteur soit différente de F:

3.2.3. Copier le fichier​

Copiez le fichier pilotes-pci-pcie.zip dans le dossier c:\drivers\ à partir de l'invite de commandes.

Réponse

copy F:\B9T\K5W\H2L\D8U\F7H\L4P\pilotes-pci-pcie.zip c:\drivers\

Il est possible que la lettre du lecteur soit différente de F:

3.2.4. Extraction​

À partir du gestionnaire de fichiers, effectuez l'extraction des fichiers dans le dossier c:\drivers\pilotes-pci-pcie\.

4. Installation des pilotes de la carte-mère Dell​

astuce

Voici les procédures nécessaires pour faire l'installation manuelle et pour trouver l'identifiant.

  • Procédures -> Windows -> Gestionnaire des périphériques -> Identification d'un périphérique

  • Procédures -> Windows -> Gestionnaire des périphériques -> Installation du pilote

4.1. Périphériques non installés (Section autres périphériques)​

Vous avez plusieurs pilotes qui ne se sont pas installés. Ce sont des pilotes en lien avec la carte réseau intégrée, le chipset et le contrôleur PCI.

Vous devez installer les périphériques manuellement.

Les pilotes se retrouvent dans le dossier c:\drivers\pilotes-dell\.

Vous devez utiliser l'identifiant du périphérique pour trouver le bon sous-dossier.

4.2. Carte graphique intégrée​

Pourquoi le deuxième écran ne fonctionne-t-il pas ? Trouvez la réponse dans le laboratoire 9.

Le pilote de la carte graphique est celui de base.

Le pilote se retrouve dans le dossier c:\drivers\pilotes-dell\.

Vous devez utiliser l'identifiant du périphérique pour trouver le bon sous-dossier.

Redémarrez l'ordinateur et le 2e écran fonctionnera.

5. Installation des pilotes des périphériques PCI et PCIe​

Pour l'installation des pièces, veuillez respecter les règles pour l'assemblage de l'ordinateur.

  • Utiliser le bracelet anti-statique
  • Débrancher tous les câbles avant d'ouvrir le boitier

Installez une carte à la fois.

Les pilotes se retrouvent dans le dossier c:\drivers\pilotes-pci-pcie\.

Vous devez utiliser l'identifiant du périphérique pour trouver le bon sous-dossier.

5.1. Carte réseau PCIe​

5.1.1. Installation de la carte​

Installez la carte réseau PCIe dans l'emplacement PCIe x16 (Câblé en x4).

Installez le pilote.

5.1.2. Questions​

1- Retirez la carte de l'ordinateur.

2- Démarrez l'ordinateur.

3- Est-ce que la carte Realtek PCIe GbE Family Controller est toujours présente dans le gestionnaire de périphériques ?

Réponse

Sous la section Cartes réseau, le périphérique n'est plus présent lorsqu'il n'est plus détecté par l'ordinateur.

4- Fermez l'ordinateur et réinstallez la carte.

5- Est-ce que vous devez réinstaller le pilote ?

Réponse

Sous la section Cartes réseau, le périphérique est présent. Il n'est pas nécessaire de réinstaller le pilote, car le pilote fait maintenant partie du magasin de pilotes de Windows (Windows DriverStore).
