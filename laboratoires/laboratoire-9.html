Laboratoire de la semaine 9

Dans ce laboratoire, vous allez effectuer vos premières configurations dans le BIOS, mettre à jour votre clé USB démarrable et installer Windows 11.

Gestion des questions et de vos vérifications

Pour vos questions, veuillez utiliser la session Handraise ci-dessous.

https://go.handraiseapp.com/join/D38G50

Cette application me permet de faciliter la gestion des questions/vérifications et de respecter votre priorité.

1. Créer une clé démarrable avec Rufus​

Pour être en mesure d'installer Windows 11, vous devez créer une clé USB démarrable à l'aide de Rufus.

Vous devez trouver le logiciel et le fichier ISO sur le disque Micron 256 Go SSD Format 2.5".

1.1. Connexion des pièces à votre ordinateur portable​

Le disque Micron 256 Go SSD Format 2.5" contient le fichier ISO pour l'installation de ce laboratoire.

1- Connectez le disque Micron 256 Go SSD Format 2.5" à l'adaptateur USB à SATA.

2- Connectez l'adaptateur USB à SATA dans un port USB 3 de votre ordinateur portable.

3- Connectez la clé USB dans un autre port USB 3 de votre ordinateur portable.

  • En cas de doute pour vos ports USB, utilisez le logiciel UsbTreeView pour voir la version de votre port USB
  • Le logiciel UsbTreeView.exe se retrouve à la racine de la partition ISO_1R1 dans votre ordinateur.
  • Assurez-vous que la clé USB et que l'adaptateur USB à SATA soit connecté.
attention

Le fichier Win11_1R1_A26.iso est une version de Windows spécifiquement adaptée pour le cours.

Il est important de toujours utiliser cette version pour les laboratoires et les examens.

Cette version ne doit pas être utilisée pour une installation sur un ordinateur qui sera réellement utilisé. Utilisez le ISO officiel sur le site de Microsoft.

1.2. Trouver la lettre du lecteur​

À partir de l'Explorateur de fichiers, identifiez la lettre du lecteur de la partition ISO_1R1.

En fonction de l'ordre de connexion des périphériques USB et de vos partitions existantes, les lettres peuvent être différentes.

1.3. Trouver le ISO dans l'invite de commandes​

Astuce pour l'examen

Ce sont des questions très intéressantes pour l'examen théorique de la semaine 12 pour voir si vous comprenez l'utilité des variables %path% et %pathext%.

Il est fort possible que vous deviez trouver un fichier dans une très grande arborescence.

Ne le dites pas trop fort, c'est un secret !

1- Ouvrez l'invite de commandes à partir de votre portable.

2- Déplacez-vous sur le lecteur que vous avez identifié pour la partition ISO_1R1.

Réponse

La commande est d:

Ou la lettre de lecteur que vous avez identifiée.

3- Cette partition contient 5460 dossiers ! Vous devez trouver l'emplacement du fichier Win11_1R1_A26.iso

Quelle est la commande pour trouver le fichier ?

Réponse

La commande est dir /s Win11_1R1_A26.iso

Le fichier ISO se retrouve dans le dossier D:\B9T\P1Z\W7E\4YG\J9X\L4P\

D: est la lettre du lecteur de la partition ISO_1R1. La vôtre peut être différente.

4- Trouvez le logiciel rufus. L'exécutable contient le mot rufus et se termine par l'extension .exe.

Quelle est la commande pour trouver le fichier à partir de la racine du lecteur ?

Réponse

La commande est dir /s *rufus*.exe

Le fichier rufus-4.15p.exe se retrouve dans le dossier D:\R4D\3FA\T6V\A0S\Q1M\E8A`

D: est la lettre du lecteur de la partition ISO_1R1. La vôtre peut être différente.

5- Tapez le nom de l'exécutable à partir de la racine du lecteur. Pourquoi ça ne fonctionne pas ?

Réponse

Le dossierD:\R4D\3FA\T6V\A0S\Q1M\E8A\ ne se retrouve pas dans la variable %path%.

Tapez echo %path% pour visualiser son contenu. Vous allez voir que le dossier ne s'y retrouve pas.

Vous devez vous déplacer dans le dossier pour le faire fonctionner.

6- Déplacez-vous dans le dossier avec la notation absolue qui contient le programme rufus.

Réponse

La commande est cd D:\R4D\3FA\T6V\A0S\Q1M\E8A\

7- Exécutez le programme. Est-ce qu'il est nécessaire d'inscrire le .exe pour exécuter le programme ?

Réponse

Le .EXE se retrouve dans la variable %pathext%.

Tapez echo %pathext% pour visualiser son contenu. Vous allez voir que le .EXE s'y retrouve.

1.4. Créer la clé fichier ISO​

Veuillez vous référer à la section Procédures -> Utilitaires -> Rufus pour avoir la procédure de création.

Utilisez le fichier ISO que vous avez trouvé à la section 1.3. Question #3.

Le processus peut prendre environ 10 à 15 minutes.

Pendant ce temps...

Débutez l'installation ergonomique et la configuration du BIOS de la section 2.

2. Préparation du poste​

2.1. Installation ergonomique du poste​

1- Installez le poste de façon ergonomique, comme vous l'avez appris en début de session.

2- L'écran doit se brancher à l'ordinateur avec le port HDMI.

3- La souris sans-fil sera transporté par l'utilisateur. Elle sera considérée comme périphérique temporaire.

4- Vous devez brancher le câble réseau à l'ordinateur.

2.2. Configuration du BIOS​

  1. Il faut enlever le mode de démarrage PXE.

    • System Configuration -> Integrated NIC : Enabled

      Cette option permet de configurer la carte réseau interne. Le mode PXE consiste à rechercher un serveur de démarrage pour charger le système d'exploitation à partir du réseau.

  2. Il faut modifier le mode de communication pour les ports SATA.

    • System Configuration -> SATA Operation : AHCI

      Cette option permet de configurer le contrôleur SATA pour déterminer le mode de communication.

  3. Il faut désactiver le Secure Boot.

    • Secure Boot -> Secure Boot Enable : Disabled

      Cette option consiste à vérifier si le périphérique de démarrage est sécurisé dans le cas où elle serait activée.

  4. Il faut activer le SATA 0. Le disque Samsung SSD 250 Go est connecté à ce port.

    • System Configuration -> Drives : Cochez SATA 0.

  5. Il faut mettre la bonne date et heure pour l'ordinateur.

    • General -> Date/Time : L'heure est en notation 12 heures AM/PM

Appuyez sur Apply pour enregistrer les modifications.

3. Installation de Windows​

Astuces

Référez-vous à la procédure qui se retrouve dans la section Procédures -> Installation de système d'exploitation -> Windows 11.

Vous devez installer Windows 11 sur le disque Samsung SSD 250 Go format 2.5". Le disque est déjà dans l'ordinateur dans le port SATA 0. Il sera détectable par l'ordinateur uniquement si le port SATA 0 est activé dans le BIOS.

Démarrez l'ordinateur sur votre clé USB.

3.1. Paramètres d'installation​

Voici les paramètres de l'installation.

Windows doit être installé sur une partition de 100 Go (Windows). Effectuez la conversion en Mo (Windows) correctement en utilisant le facteur 1024.

Vous devez installer l'édition Professionnel.

Le nom d'utilisateur doit être Etudiant et il ne doit pas avoir de mot de passe.

La disposition du clavier doit être Français (Canada).

4. Installation d'un 2e écran​

Demandez le 2e écran à l'enseignant.

1- Éteignez l'ordinateur.

2- Installez un 2e écran.

  • L'installation doit être ergonomique au niveau des connexions.
  • Vous avez une seule option.

3- Démarrez l'ordinateur.

  • Est-ce que les 2 écrans fonctionnent ? Pourquoi ?
Réponse

Le 2e écran ne fonctionne pas, car le pilote de la carte graphique est un pilote de base. Ce pilote permet d'avoir un affichage minimal pour être en mesure de faire les premières configurations. Ce pilote n'est pas en mesure de gérer plusieurs écrans. Il faut donc installer le vrai pilote pour la carte graphique.

Astuce pour l'examen

Lisez bien la réponse, ça vous aidera peut-être pour l'examen théorique final.

5. Installation des pilotes de base​

Vous devez utiliser le site Dell Support pour installer les pilotes de base de l'ordinateur.

Dans le Gestionnaire de périphériques, vous allez voir les pilotes ci-dessous qui ne sont pas installés.

  • La section Autres périphériques (Jaune) contient les périphériques sans pilotes
  • Contrôleur Ethernet est la carte réseau intégrée à l'ordinateur.
    • Même avec un câble réseau connecté à Internet, l'ordinateur ne peut pas communiquer avec un réseau tant que le pilote n'est pas installé.
  • Les périphériques en vert sont principalement associés au chipset et à des bus de la carte-mère.
  • La section Carte vidéo a un périphérique Carte vidéo de base Microsoft. Il s'agit d'un pilote de base pour assurer un affichage minimal.
    • C'est la raison pour laquelle le 2e écran ne fonctionnait pas à l'étape 4.

5.1. Carte réseau​

La première étape consiste à avoir accès à Internet.

1- Allez dans la fiche de l'ordinateur sur le site Dell Support à partir de votre ordinateur portable. Procédures -> Dell Support -> Accès à Dell Support

2- Téléchargez le pilote de la catégorie Réseau. Procédures -> Dell Support -> Obtenir un pilote spécifique

  • Le nom sera différent.

3- Copiez le fichier sur la clé USB.

4- Branchez la clé USB sur l'ordinateur du laboratoire.

5- Copiez le fichier de la clé USB dans le dossier c:\drivers\ de l'ordinateur du laboratoire.

6- Exécutez ce fichier sur l'ordinateur du laboratoire pour installer le pilote. Il est possible que vous ayez un avertissement Smartscreen. Vous pouvez exécuter le fichier.

7- Vérifiez dans le Gestionnaire de périphériques que le pilote de la carte réseau est correctement installé.

Important

Conservez ce pilote dans votre ordinateur portable, car il vous sera utile plusieurs fois et à l'examen de la semaine 15.

Copiez le également sur l'ordinateur de votre partenaire si vous êtes en équipe.

5.2. Utilitaire Dell Support Assist​

L'utilitaire va détecter les pilotes manquants et ensuite les installer automatiquement. Cette étape peut prendre plusieurs minutes.

1- Allez dans la fiche de l'ordinateur sur le site Dell Support à partir de l'ordinateur du laboratoire. Procédures -> Dell Support -> Accès à Dell Support

2- Installez Dell Support Assist. Procédures -> Dell Support -> Dell Support Assist

3- Sélectionnez tous les pilotes proposés pour l'installation.

  • À l'exception de Intel Rapide Storage
attention

Cette étape peut prendre plusieurs minutes. Lisez bien la procédure.

Il y a plusieurs étapes et une erreur peut empêcher l'analyse de l'ordinateur.

  • Le 2e écran devrait fonctionner lorsque le pilote de l'écran sera mis à jour.

3- Vérifiez dans le Gestionnaire de périphériques que la liste des périphériques non installés ait diminué et que le pilote de la carte graphique ne soit plus celui de base.

5.3. Pilotes restants - Chipset​

Il reste encore trois pilotes. Ces pilotes sont avec le Chipset. Normalement, ils auraient été installés par Windows Update, mais la fonctionnalité a été désactivée pour être en mesure d'apprendre à installer des pilotes.

1- Faites comme à l'étape 5.1. et téléchargez et installez ce pilote. Vous pouvez le faire directement de l'ordinateur du laboratoire ou de votre portable. Conservez ce pilote dans votre ordinateur portable. Il vous sera utile pour l'examen et les prochains laboratoires.

  • Prenez celui de la catégorie Jeu de puce. Le nom sera différent que l'image ci-dessous.

2- Vérifiez dans le Gestionnaire de périphériques que la section Autres périphériques ne soit plus présente.

6. Configuration de Windows​

Vous devez faire les configurations de Windows. Ce sont des configurations que vous avez effectuées au début de l'année.

6.1. Disposition des écrans​

Il faut que la disposition des écrans soit faite correctement.

6.2. Nom de l'ordinateur​

Le nom de l'ordinateur doit être Gr#Tb@.

Le # représente votre numéro de groupe et le @ représente votre table de travail qui est inscrite sur la tablette.

Exemple : si vous êtes le groupe 5 et que vous avez la table 2, l'ordinateur doit se nommer Gr5Tb2

Il est important de respecter les majuscules et minuscules.

6.3. Disposition du clavier​

Il faut avoir la disposition Français (Canada) et Anglais (États-Unis).

6.4. Explorateur de fichiers​

Il faut afficher les extensions des fichiers.

Il faut afficher les fichiers masqués.

Il faut mettre Ce PC et non Accueil à l'ouverture de l'Explorateur de fichiers.

9. Réinitialisation du disque Samsung et de la clé USB​

Vous devez réinitialiser le disque Samsung SSD 250 Go format 2.5" pour effacer son contenu.

1- Fermez l'ordinateur.

2- Démarrez l'ordinateur sur votre clé USB.

3- Lorsque le programme d'installation de Windows apparaît, appuyez sur la touche MAJ + F10 pour ouvrir l'invite de commandes.

4- Dans l'invite de commandes, inscrivez les commandes ci-dessous. DiskPart est l'utilitaire en invite de commandes pour faire la gestion des disques.

diskpart

5- Dans DiskPart, inscrivez les commandes ci-dessous pour effacer complètement le disque.

select disk 0
clean
convert gpt

select disk 1
clean
convert mbr

exit

Le disque 0 devrait être le disque Samsung SSD 250 Go et le disque 1 la clé USB.

6- Débranchez la clé USB et redémarrez l'ordinateur.

Vous devriez avoir le message No bootable device si le disque est correctement effacé. Que signifie ce message ?

Réponse

Ce message signifie que le BIOS n'a pas trouvé de système d'exploitation sur les unités de stockage internes ou USB.

Dans le cas où il n'y aurait aucun disque interne ou où son port SATA ou M.2 ne serait pas activé dans le BIOS, il est possible d'avoir ce message.

astuce

Pourquoi je mets une astuce ? La compréhension de la réponse est peut-être importante.

6- Branchez la clé USB et redémarrez l'ordinateur. Sélectionnez la clé USB. Vous ne devriez pas être en mesure de démarrer avec le programme d'installation de Windows si la clé est correctement effacée.

10. BIOS​

Il faut remettre le BIOS en désordre pour le prochain groupe.

  1. Il faut mettre le mode de démarrage PXE.

    • System Configuration -> Integrated NIC : Enabled w/PXE

  2. Il faut modifier le mode de communication pour les ports SATA.

    • System Configuration -> SATA Operation : RAID On

  3. Il faut désactiver le SATA 0.

    • System Configuration -> Drives : Décochez SATA 0

  4. Il faut activer le Secure Boot.

    • Secure Boot -> Secure Boot Enable : Enabled

  5. Il faut mettre une mauvaise date et heure pour l'ordinateur.

    • General -> Date/Time : L'heure est en notation 12 heures AM/PM

Appuyez sur Apply pour enregistrer les modifications.
