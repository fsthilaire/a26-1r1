Laboratoire de la semaine 10

Vous allez utiliser l'utilitaire Gestion des disques pour effectuer des manipulations sur les disques.

La première heure sera utilisée pour les notions théoriques sur la gestion des disques.

La deuxième heure sera consacrée aux activités des sections 1 à 3 du laboratoire.

La troisième heure sera utilisée pour les notions théoriques pour l'installation d'un pilote manuellement et pour faire les sections 4 à 6.

1. Vérifier Windows​

1- Insérez le disque Samsung 250 Go SSD Format 2.5" dans le tiroir SATA du haut. Il est connecté dans le port SATA 1.

2- Insérez le disque Seagate 500 Go HDD Format 3.5" dans le tiroir SATA du bas.

3- Connectez le disque Micron 256 Go SSD Format 2.5" à l'adaptateur USB à SATA.

4- Branchez l'adaptateur USB à SATA dans un port USB 3 de l'ordinateur du laboratoire.

5- Démarrez l'ordinateur pour accéder à Windows.

Pourquoi Windows ne démarre-t-il pas ?

La réponse est dans le BIOS. Il est protégé par un mot de passe. L'enseignant vous le donnera en classe.

Indice

Pensez à ce que vous faisiez pour vérifier si une unité de stockage était bien connectée.

2. Gestion des partitions​

Utilisez les procédures de la section Procédures -> Windows -> Gestion des disques pour vous aider à répondre aux questions ci-dessous.

Examen

Ce type de questions vous sera demandé lors de l'examen du cours théorique 12.

2.1. Disque Samsung 250 Go SSD Format 2.5"​

1- Pour le disque Samsung 250 Go SSD Format 2.5", veuillez identifier la taille, la lettre du lecteur et le système de fichiers pour les partitions nommées OS, DATA, BCK, 1R1 et OLD.

Réponse

OS : 67,38 Go NTFS (C:)
DATA : 28,5 Go FAT32 (F:)
BCK : 102 Go exFAT (R:)
1R1 : 11 Go NTFS (N:)
OLD : 2 Go FAT (O:)

2- Combien y a-t-il de partitions au total sur ce disque ?

Réponse

Il y a 7 partitions.
La partition de 200 Mo est la partition de démarrage EFI de Windows
La partition de 787 Mo est la partition de récupération. Elle sert à avoir les outils de dépannage en cas de défaillance de Windows.
Le 21,02 Go restant n'est pas une partition. C'est de l'espace inutilisé restant du disque.

2.2. Disque Micron 256 Go SSD Format 2.5"​

2.2.1. Identification du style de partition​

Identifiez le style de partition du disque.

Réponse

GPT

2.2.2. Identification des partitions​

Identifiez le nom, la taille et le système de fichiers pour les partitions du disque Micron 256 Go SSD Format 2.5".

Réponse

NT : 120 Go NTFS
FT : 12 Go FAT32
XFT : 75 Go exFAT

2.2.3. Questions​

1- Copiez le fichier WinPEx64_A26.iso de la partition NT vers la partition FT. Faites la même chose pour le fichier Win11_1R1_A26.iso. Pourquoi cela ne fonctionne-t-il pas pour Win11_1R1_A26.iso ?

Réponse

La partition FT est en FAT32. La taille maximale d'un fichier est de 4 Go pour ce système de fichiers.

Le fichier WinPEx64_A26.iso est de 580 Mo environ.

Le fichier Win11_1R1_A26.iso est de 8,10 Go environ.

2- Créez une partition en FAT32 sur l'espace restant du disque. Est-ce que c'est possible ?

Réponse

La taille maximale d'une partition FAT32 est de 32 Go. Il reste plus de 32 Go dans l'espace disponible.

3- Vous voulez copier des fichiers vers plusieurs autres systèmes. Quelle partition est recommandée d'utiliser pour avoir le maximum de compatibilité ?

Réponse

La partition FT est en FAT32. Ce système de fichiers est le plus universel.

4- Je veux mettre de la sécurité sur mes fichiers. Seulement certains utilisateurs peuvent consulter ces fichiers. Quelle partition permet de faire ceci ?

Réponse

La partition NT est en NTFS. Ce système de fichiers permet d'avoir de la sécurité sous Windows. FAT32 et exFAT ne permettent pas de gérer la sécurité.

2.3. Disque Seagate 500 Go Format 3.5"​

2.3.1. Initialisation du disque​

Le disque n'est pas initialisé.

Initialisez le disque en MBR.

2.3.2. Création de partitions​

Créez les partitions ci-dessous sur le disque Seagate 500 Go HDD Format 3.5".

NomSystème de fichiersTailleLettre
VOL1exFAT89 GoR
VOL2NTFS78 GoW
VOL3FAT3229 GoK
VOL4FAT3231 GoL
VOL5NTFS17 GoM
VOL6exFATEspace restant - 1,5 GoN
Avertissement

Vous êtes dans Windows, il faut utiliser le facteur 1024.

Réponse

L'utilitaire indique qu'il reste 227 079 Mo disponibles.
Il faut convertir 1,5 Go en Mo => 1,5 * 1024 = 1536 Mo.
Il faut déduire 1536 Mo des 227 079 Mo disponibles => 227 079 - 1536 = 225 543 Mo.
Le Vol 6 doit avoir 225 543 Mo pour avoir un espace restant de 1,5 Go

2.3.3. Question​

Pourquoi les 3 dernières partitions sont-elles d'une autre couleur ?

Réponse

Le style de partition MBR permet uniquement 4 partitions principales.

Avec Windows, lorsque la 4e partition ne prend pas l'entièreté du disque, l'espace restant est converti en mode étendu. Ceci permet d'avoir d'autres partitions, mais ce n'est pas optimal comme technique.

Le disque aurait dû être initialisé en GPT pour permettre 6 partitions principales.

4. Installation de périphériques​

Note

Référez-vous aux procédures qui se retrouvent dans la section Procédures -> Windows -> Gestionnaire de périphériques.

Vous devez installer différents périphériques.

Certaines pièces doivent être partagées entre les équipes.

Conservez tous les pilotes fonctionnels que vous téléchargez sur Internet. Ils vous seront utiles lors des prochains laboratoires et lors de l'examen.

Installez une pièce à la fois.

Comment trouver les pilotes

Sur le site web des fournisseurs, il y a une section support ou pilotes / drivers. Dans cette section, vous pouvez inscrire le modèle de votre pièce.

Téléchargez la version la plus récente de Windows disponible. Si vous avez l'option entre 32 bits ou 64 bits, prenez celle de votre installation de Windows (64 bits).

4.1. Carte réseau sans-fil USB​

4.1.1. Installation du pilote​

Cette pièce n'est plus prise en charge par la compagnie Linksys. Le pilote ne peut pas être trouvé sur le site web du fournisseur.

Le pilote se retrouve dans un des sous-dossiers avec un code alphanumérique à 4 caractères du dossier c:\drivers\.

Dans ce dossier, il y a des sous-dossiers classés par numéro fournisseur (VID ou VEN). À l'intérieur du dossier fournisseur, il y a des fichiers ZIP qui correspondent au numéro de la pièce (PID ou DEV). Il faut extraire ce zip et faire l'installation manuellement.

Vous devez récupérer l'identifiant du périphérique pour obtenir ces numéros.

Astuce

Pour obtenir l'identifiant, référez-vous au document Procédures -> Windows -> Gestionnaire de périphériques -> Identification d'un périphérique.

4.1.2. Détection de la version du port USB​

Utilisez le logiciel UsbTreeView. Le logiciel se retrouve sur la partition Outils de la clé USB. Copiez-le dans le dossier c:\apps\UsbTreeView\.

Branchez les périphériques dans un port USB 3, car le logiciel ne sera pas en mesure de détecter une version supérieure du port USB dans lequel il est connecté.

Réponse

USB 2.00
Il serait préférable de connecter ce périphérique dans un port USB 2 s'il y en a un de disponible sur l'ordinateur.

4.2. Carte réseau PCI - Startech​

Regardez la pièce. Il y a un identifiant avec le site web du fournisseur et un numéro de pièce.

Avertissement

Recherchez le pilote sur les sites web du fournisseur.

Vous devez extraire le fichier zip dans le dossier c:\drivers\.

N'utilisez pas le programme d'installation Setup.exe.

Le pilote se retrouve dans le dossier Manual Drivers.

Trouvez le sous-dossier qui contient le fichier inf pour la version la plus récente de Windows et pour la bonne architecture.
