Laboratoire de la semaine 12

Dans ce laboratoire, vous allez apprendre à installer Mint Linux sur un poste de travail.

1. Démarrage de Windows PE​

1- Insérez le disque Micron 256 Go SSD 2.5" dans le tiroir SATA du haut.

2- Insérez la clé USB du laboratoire dans un port USB 3.

3- Démarrez l'ordinateur sur la clé USB.

4- Sélectionnez WinPEx64_A26.iso dans Ventoy.

Pourquoi le clavier ne répond-il pas ? Le clavier est bien branché et fonctionnel. Il y a quelque chose dans le BIOS.

Indice

C'est dans une section en lien avec les ports USB sous System Configuration.

Je vous donne la réponse dans 5 minutes.

2. Installer Linux Mint​

1- Insérez le disque Micron 256 Go SSD Format 2.5" dans le tiroir SATA du haut.

2- Démarrez l'ordinateur à partir de la clé USB.

3- Dans le menu Ventoy, sélectionnez linuxmint-22.3-cinnamon-64bit.iso.

4- Suivez les étapes de la procédure d'installation qui se retrouve dans la section Procédures -> Installation de système d'exploitation -> Linux Mint 22.3.

5- Voici les paramètres pour l'installation

  • Nom de l'ordinateur : LinuxTb# Remplacez le # par le numéro de table.

  • Votre nom : Inscrivez votre nom. Pour les équipes, inscrivez seulement un seul nom.

  • Nom d'utilisateur : francois

  • Mot de passe : Labo13!

  • Langue : Français

  • Disposition du clavier : Français (Canada)

3. Installation de logiciels​

Sous Linux, il y a plusieurs façons d'installer un logiciel. Dans ce laboratoire, vous allez en essayer trois.

3.1. Avec la Logithèque​

La Logithèque est le « magasin d'applications » de Linux Mint. Elle permet de chercher et d'installer des logiciels sans utiliser le terminal.

Vous allez installer les trois logiciels suivants.

LogicielUtilité
GPartedÉditeur de partitions (sera utilisé la semaine prochaine)
HardInfoAffiche les informations sur le matériel de l'ordinateur
Chromium (ou Brave)Navigateur web alternatif à Firefox

3.1.1. GParted​

1- Cliquez sur le bouton du menu (1), puis sur Logithèque (2).

2- Tapez gparted dans la zone de recherche et appuyez sur Entrée, puis cliquez sur le résultat GParted (2).

3- Cliquez sur Installer (3).

4- Le logiciel a besoin d'autres paquets pour fonctionner (des dépendances) : la Logithèque affiche la liste des logiciels supplémentaires. Lisez la liste, puis cliquez sur Poursuivre (4).

5- Tapez votre mot de passe, puis cliquez sur S'authentifier (5).

6- Attendez la fin de l'installation : les boutons Lancer et Supprimer remplacent le bouton Installer.

3.1.2. HardInfo​

1- Tapez hardinfo dans la zone de recherche de la Logithèque et appuyez sur Entrée, puis cliquez sur le résultat Hardinfo (1).

2- Cliquez sur Installer (2).

3- Lisez la liste des logiciels supplémentaires, puis cliquez sur Poursuivre (3). Si le mot de passe est demandé, tapez-le et cliquez sur S'authentifier.

remarque

Si vous venez de saisir votre mot de passe pour GParted, il n'est pas redemandé : l'autorisation reste valide quelques minutes.

4- Attendez que les boutons Lancer et Supprimer apparaissent.

3.1.3. Chromium​

1- Tapez chromium dans la zone de recherche de la Logithèque et appuyez sur Entrée. Remarquez que certains résultats portent la mention Flatpak (par exemple Ungoogled Chromium). Cliquez sur le résultat Chromium (1).

2- Repérez la mention Paquet système sous le bouton Installer, puis cliquez sur Installer (2).

3- Tapez votre mot de passe, puis cliquez sur S'authentifier (3).

4- Attendez la fin de l'installation (le téléchargement est plus gros, environ 130 Mo) : les boutons Lancer et Supprimer apparaissent. Fermez ensuite la Logithèque.

Question-défi

Quelle est la différence entre un paquet système et un Flatpak ?

Réponse

Un paquet système (APT) utilise les bibliothèques partagées du système. Il est léger, mais sa version dépend de la version de Linux Mint.

Un Flatpak est livré avec ses propres dépendances, dans un environnement isolé. Il est plus lourd, mais il peut être plus récent et fonctionne de la même façon sur plusieurs distributions Linux.

3.1.4. Vérification​

Vérifiez que les trois logiciels sont bien installés en les lançant à partir du menu.

1- Ouvrez le menu, tapez hardinfo dans la zone de recherche, puis cliquez sur Informations et Benchmarks.

remarque

Dans le menu, HardInfo porte le nom Informations et Benchmarks (sa fenêtre s'intitule « Informations du Système »).

2- Observez le résumé affiché par HardInfo, puis fermez la fenêtre.

3- Ouvrez le menu, tapez chromium, puis appuyez sur Entrée. Vérifiez que le navigateur s'ouvre, puis fermez la fenêtre.

4- Ouvrez le menu, tapez gparted et appuyez sur Entrée. GParted demande votre mot de passe à chaque ouverture, car il s'exécute avec les privilèges d'administrateur (root). Tapez votre mot de passe et cliquez sur S'authentifier.

attention

Dans GParted, regardez seulement. Ne cliquez sur aucune opération (créer, supprimer, formater, redimensionner). Un seul clic peut effacer des données. Nous allons l'utiliser la semaine prochaine.

5- Observez les partitions du disque sans rien modifier, puis fermez GParted.

3.2. Avec APT​

APT est le gestionnaire de paquets en ligne de commande. C'est aussi l'outil qu'utilise le Gestionnaire de mise à jour (section 6).

1- Ouvrez un terminal avec le raccourci Ctrl + Alt + T.

2- Actualisez la liste des paquets disponibles : tapez la commande suivante, appuyez sur Entrée, puis tapez votre mot de passe et appuyez sur Entrée.

sudo apt update
info

Quand vous saisissez votre mot de passe dans le terminal, rien ne s'affiche à l'écran (pas d'étoiles, pas de points). C'est normal. Tapez votre mot de passe et appuyez sur Entrée.

Le mot de passe reste mémorisé environ 15 minutes : les commandes sudo suivantes ne le redemandent pas.

3- Attendez la fin de la commande et lisez la dernière ligne.

Question-défi

Quelle est la différence entre apt update et apt upgrade ?

Réponse

apt update actualise la liste des paquets et des versions disponibles. Il n'installe rien.

apt upgrade installe les nouvelles versions des paquets déjà présents.

3.2.1. htop​

htop est un moniteur de processus en temps réel. C'est l'équivalent du Gestionnaire des tâches de Windows, dans le terminal.

1- Affichez les informations du paquet : tapez la commande suivante et appuyez sur Entrée.

apt show htop

2- Installez le paquet : tapez la commande suivante et appuyez sur Entrée.

sudo apt install htop

Appuyez sur O (ou Y) puis Entrée lorsque le système demande une confirmation.

remarque

APT demande une confirmation seulement lorsqu'il doit installer des paquets supplémentaires (des dépendances). Pour htop, il n'y en a pas : l'installation se fait directement.

3- Lancez le logiciel : tapez la commande suivante et appuyez sur Entrée. Observez les barres en haut de l'écran (processeur et mémoire) et la liste des processus.

htop

4- Cliquez sur l'en-tête de la colonne MEM% (1) pour trier les processus selon la mémoire utilisée.

5- Appuyez sur la touche q pour quitter.

Question-défi

Quel est le processus qui utilise le plus de mémoire sur votre ordinateur ? Combien de mémoire utilise-t-il ?

Réponse

Le résultat varie selon l'ordinateur. En général, c'est le navigateur (Firefox) ou le bureau (Cinnamon). La colonne RES indique la mémoire utilisée par le processus.

3.2.2. neofetch​

neofetch affiche un résumé du système avec le logo de la distribution. Il est très populaire pour partager une capture d'écran de son installation Linux.

1- Affichez les informations du paquet.

apt show neofetch

2- Installez le paquet : tapez la commande suivante et appuyez sur Entrée.

sudo apt install neofetch
remarque

Si le paquet est déjà installé, APT l'indique (« déjà la version la plus récente ») et ne fait rien. Ce n'est pas une erreur.

3- Lancez le logiciel : tapez la commande suivante et appuyez sur Entrée.

neofetch

Question-défi

Quelle est la version du noyau (Kernel) et quel est l'environnement de bureau (DE) de votre ordinateur ?

Réponse

Le noyau est à la ligne Kernel (ex. 6.x.x-generic). L'environnement de bureau est à la ligne DE : Cinnamon.

3.2.3. hwinfo​

hwinfo détecte le matériel de l'ordinateur et affiche des informations détaillées. Comme HardInfo, c'est un utilitaire d'information sur le matériel, mais en ligne de commande.

1- Affichez les informations du paquet.

apt show hwinfo

2- Installez le paquet : tapez la commande suivante et appuyez sur Entrée. Cette fois, APT doit installer des dépendances et demande une confirmation : tapez O puis Entrée.

sudo apt install hwinfo

3- Affichez la liste résumée du matériel détecté : tapez la commande suivante et appuyez sur Entrée. Attendez la fin, puis remontez avec Maj + Page précédente.

sudo hwinfo --short
info

La détection peut prendre jusqu'à une minute. Attendez le retour de l'invite de commande. Si le résultat dépasse l'écran, remontez avec Maj + Page précédente ou la molette de la souris.

4- Affichez seulement les disques : tapez la commande suivante et appuyez sur Entrée.

sudo hwinfo --disk --short

Question-défi

Quel est le modèle du processeur et quel est le modèle du disque d'installation ? Comparez avec les informations de HardInfo.

Réponse

Le processeur se trouve dans la section cpu et le disque dans la section disk. Les informations sont les mêmes que dans HardInfo, mais présentées différemment.

Les résultats varient selon l'ordinateur du poste de travail.

3.3. Avec un fichier .deb​

Certains logiciels ne sont pas dans les dépôts de Linux Mint. L'éditeur offre alors un fichier d'installation au format .deb (l'équivalent d'un fichier .exe ou .msi sous Windows). Nous allons installer Visual Studio Code.

1- Ouvrez Firefox, tapez code.visualstudio.com dans la barre d'adresse et appuyez sur Entrée. Si un bandeau sur les témoins (cookies) apparaît, cliquez sur Reject pour refuser les témoins optionnels. Cliquez ensuite sur other platforms (1).

2- Dans la carte Linux, ouvrez la liste Select a download… (1), puis cliquez sur .deb x64 (2).

remarque

Le bouton Download for Linux (.deb) de la page d'accueil télécharge aussi la bonne version. La liste de l'étape 2 permet de voir toutes les architectures offertes.

Question-défi

Pourquoi faut-il choisir la version x64 et non Arm64 ou Arm32 ?

Réponse

Le processeur de l'ordinateur est de type Intel/AMD 64 bits (architecture x86-64, aussi appelée amd64), qui correspond à la version x64.

Les versions Arm sont pour les processeurs Arm, comme ceux des Raspberry Pi ou des Mac Apple Silicon.

3- Attendez que le panneau des téléchargements affiche Terminé, puis fermez Firefox. Le fichier est enregistré dans le dossier Téléchargements.

4- Cliquez sur l'icône du gestionnaire de fichiers dans la barre des tâches, ouvrez le dossier Téléchargements, puis faites un double-clic sur le fichier code_...amd64.deb (1).

5- L'Installateur de paquets s'ouvre. Lisez la description du logiciel, puis cliquez sur Installer le paquet (2).

6- Tapez votre mot de passe et cliquez sur S'authentifier. Une fenêtre Configuration de code demande s'il faut ajouter le dépôt APT de Microsoft : laissez la case cochée et cliquez sur Next (3).

7- Attendez le message de réussite, puis fermez l'Installateur de paquets et le gestionnaire de fichiers.

8- Ouvrez le menu, tapez visual studio (ou ouvrez la catégorie Programmation), puis cliquez sur Visual Studio Code.

9- À la première ouverture, VS Code propose de se connecter à un compte. Ce n'est pas nécessaire : cliquez sur Continue without Signing In, en bas à droite.

10- Ouvrez le Gestionnaire de mise à jour à partir du menu, puis cliquez sur Actualiser (1).

remarque

À la première ouverture, le Gestionnaire de mise à jour peut afficher une fenêtre d'accueil (cliquez sur Valider), proposer un miroir local (cliquez sur Non) ou demander de se mettre à jour lui-même. Ces écrans sont expliqués à la section 6. Pour l'instant, observez seulement la liste : n'installez pas les mises à jour avant la section 6.

Question-défi

Comment Visual Studio Code sera-t-il mis à jour dans le futur ?

Réponse

L'installation du paquet ajoute automatiquement le dépôt de Microsoft aux sources de logiciels du système. Les mises à jour de VS Code sont donc offertes avec les autres mises à jour dans le Gestionnaire de mise à jour.

Pour voir ce dépôt dans le terminal : ouvrez un terminal (Ctrl + Alt + T) et tapez les commandes ls /etc/apt/sources.list.d/ et cat /etc/apt/sources.list.d/vscode.sources, chacune suivie de Entrée.

4. Monter des partitions​

Sous Linux, pour que le contenu d'une partition soit accessible, elle doit être montée vers un dossier (le dossier de montage). Dans cette section, vous allez monter les partitions d'un disque avec l'utilitaire Disques et accéder à leur contenu.

1- Fermez l'ordinateur et retirez la clé USB.

2- Insérez le disque Samsung 250 Go SSD Format 2.5" dans le tiroir du bas.

3- Démarrez l'ordinateur.

4.1. Mise en situation​

Le disque /dev/sdb est le Samsung 250 Go SSD Format 2.5". Il utilise le style de partition GPT et contient 3 partitions.

PartitionIdentifiantTailleSystème de fichiersContenu
PART1/dev/sdb130 GoFAT32Dossiers Documents et Photos, fichier lisezmoi.txt
PART2/dev/sdb2100 GoNTFSDossier Projets, fichier notes.txt
PART3/dev/sdb3120 GoExt4Dossier Archives, fichier config.txt
info

Les partitions ne sont pas montées au début de l'exercice. Leur contenu n'est donc pas accessible tant qu'elles ne sont pas montées.

1- Ouvrez le menu, tapez disques dans la zone de recherche, puis cliquez sur Disques. Sélectionnez le disque de 250 GB dans la liste de gauche (1).

Repérez l'identifiant du disque (/dev/sdb), le style de partition (GUID Partition Table) et les 3 partitions.

remarque

L'utilitaire Disques affiche les tailles en métrique (facteur multiplicateur 1000). La partition de 120 Go est l'espace restant du disque après les deux premières partitions.

4.2. Monter une partition FAT32​

1- Dans Disques, sélectionnez la partition PART1 (1), puis cliquez sur le bouton Triangle pour la monter (2).

2- La partition est montée. Le dossier de montage est indiqué en vert : /media/nomutilisateur/PART1.

Par défaut, Linux Mint monte les partitions dans un dossier au nom de leur étiquette, sous /media/nomutilisateur.

3- Ouvrez le gestionnaire de fichiers (Nemo). Dans la section Périphériques, cliquez sur PART1 (1). Le symbole d'éjection à droite indique que la partition est montée.

4- Observez le contenu de la partition.

5- Faites un clic droit dans un espace vide, puis cliquez sur Créer un nouveau dossier (1). Nommez le dossier Travaux et appuyez sur Entrée.

6- Faites de nouveau un clic droit, placez la souris sur Créer un nouveau document (2), puis cliquez sur Document vide (3). Nommez le fichier devoir.txt et appuyez sur Entrée.

7- Le dossier et le fichier sont ajoutés sur la partition. Fermez Nemo.

8- Ouvrez un terminal (Ctrl + Alt + T). Tapez les commandes suivantes pour aller dans le dossier de montage et afficher son contenu, chacune suivie de Entrée. Remplacez nomutilisateur par votre nom d'utilisateur.

cd /media/nomutilisateur/PART1
ls

Le terminal affiche le même contenu que Nemo, incluant le dossier Travaux et le fichier devoir.txt.

Question-défi

Pourquoi le terminal et Nemo affichent-ils le même contenu ?

Réponse

Le dossier de montage /media/nomutilisateur/PART1 donne accès au contenu de la partition /dev/sdb1. Peu importe l'outil utilisé (Nemo ou le terminal), on accède à la même partition par le même dossier.

4.3. Changer le dossier de montage​

1- Dans Disques, sélectionnez la partition PART2 (1), puis cliquez sur le bouton Triangle (2).

2- La partition est montée dans /media/nomutilisateur/PART2.

3- Dans Nemo, cliquez sur PART2 dans la section Périphériques et observez son contenu.

4- Faites un clic droit dans un espace vide, placez la souris sur Créer un nouveau document, puis cliquez sur Document vide. Nommez le fichier inventaire.txt. Fermez ensuite Nemo.

Le dossier de montage ne peut pas être modifié pendant que la partition est montée. Il faut d'abord la démonter.

5- Dans Disques, sélectionnez PART2 et cliquez sur le bouton Carré (1) pour démonter la partition.

6- Cliquez sur le bouton Engrenage (1), puis sur Modifier les options de montage… (2).

7- Désactivez Réglages par défaut de la session utilisateur (1). Les champs deviennent modifiables. En orange, le point de montage par défaut.

8- Dans le champ Point de montage, tapez /mnt/zone2, puis cliquez sur Valider (2).

info

L'option Monter au démarrage du système est cochée par défaut : la partition sera montée automatiquement dans /mnt/zone2 à chaque démarrage de l'ordinateur.

9- Tapez votre mot de passe, puis cliquez sur S'authentifier (3). Le mot de passe est demandé, car les options de montage sont enregistrées dans le fichier système /etc/fstab.

10- Une étoile est maintenant affichée sur la partition : elle a une entrée dans /etc/fstab. Cliquez sur le bouton Triangle (1) pour monter la partition.

11- La partition est maintenant montée dans /mnt/zone2.

12- Ouvrez Nemo, appuyez sur Ctrl + L, tapez /mnt/zone2 et appuyez sur Entrée. Le contenu est le même qu'avant, incluant le fichier inventaire.txt : seul le dossier de montage a changé.

Question-défi

Le fichier inventaire.txt est-il encore présent dans /media/nomutilisateur/PART2 ?

Réponse

Non. Les fichiers sont enregistrés sur la partition /dev/sdb2, pas dans le dossier de montage. Le dossier de montage est seulement le chemin d'accès à la partition. Maintenant, ce chemin est /mnt/zone2.

4.4. Partition Ext4 et mode administrateur​

1- Dans Disques, sélectionnez la partition PART3 (1), puis cliquez sur le bouton Triangle (2).

2- La partition est montée dans /media/nomutilisateur/PART3.

3- Dans Nemo, cliquez sur PART3 dans la section Périphériques (1), puis faites un double-clic sur le fichier config.txt (2).

4- Le fichier s'ouvre dans l'Éditeur de texte. Remarquez la mention [Lecture seule] dans la barre de titre : il est possible de lire le fichier, mais pas de le modifier. Fermez l'éditeur de texte.

5- Dans Nemo, faites un clic droit dans un espace vide de PART3. Les options Créer un nouveau dossier et Créer un nouveau document sont grisées : votre utilisateur n'a pas le droit d'écrire sur cette partition.

Question-défi

Pourquoi est-il possible de créer des fichiers sur PART1 et PART2, mais pas sur PART3 ?

Réponse

Les systèmes de fichiers FAT32 et NTFS ne gèrent pas les permissions de Linux. Linux Mint les monte en donnant les droits à l'utilisateur qui les monte.

Le système de fichiers Ext4 conserve les permissions de Linux. Les fichiers et dossiers de PART3 appartiennent à l'administrateur (root) : il faut donc être administrateur pour les modifier.

6- Cliquez sur Ouvrir en tant que superutilisateur (1). Tapez votre mot de passe, puis cliquez sur S'authentifier (2).

7- Une nouvelle fenêtre de Nemo s'ouvre avec la bande rouge Privilèges élevés. Faites un clic droit, placez la souris sur Créer un nouveau document (3), puis cliquez sur Document vide (4). Nommez le fichier rapport-admin.txt.

8- Le fichier est créé sur la partition.

attention

En mode administrateur, il est possible de modifier ou de supprimer des fichiers système. Fermez la fenêtre Privilèges élevés dès que vous avez terminé.

5. Exploration de Linux Mint​

Dans cette section, vous allez explorer quelques paramètres de Linux Mint.

1- Ouvrez le menu et cliquez sur Paramètres du système, dans la colonne de gauche.

remarque

La zone de recherche en haut à droite des Paramètres du système permet de trouver rapidement un module (par exemple, tapez « clavier »).

5.1. Personnalisation du bureau​

1- Cliquez sur Thèmes. Changez le mode (clair, sombre ou mixte), par exemple Sombre (1), puis la couleur d'accent (2). Observez les changements.

2- Cliquez sur la flèche de retour (en haut à gauche), ouvrez Arrière-plans, puis cliquez sur une image (1) pour changer le fond d'écran.

3- Faites un clic droit sur un espace vide de la barre des tâches (le panneau en bas) (1), puis cliquez sur l'interrupteur Mode de modification du panneau (2).

4- Faites de nouveau un clic droit sur le panneau, puis cliquez sur Applets.

5- Cliquez sur une applet, par exemple Afficher le bureau (1), puis sur le bouton + (2) pour l'ajouter au panneau. Fermez ensuite la fenêtre Applets.

6- Glissez la nouvelle applet avec la souris jusqu'à un autre emplacement, par exemple près de l'horloge.

7- Quittez le mode modification : clic droit sur le panneau, puis désactivez Mode de modification du panneau.

Question-défi

Dans Thèmes, cliquez sur Paramètres avancés… et repérez le thème des icônes et le thème des applications (fenêtres). Changez un seul des deux. Que constatez-vous ?

Réponse

Les éléments du bureau sont indépendants : l'apparence des fenêtres, des icônes, des boutons et du pointeur se règle séparément, ce qui permet de combiner les thèmes.

Par exemple, dans Paramètres avancés…, cliquez sur l'aperçu des Icônes et choisissez une autre couleur (ex. Mint-Y-Orange) : les dossiers changent de couleur, mais pas les fenêtres.

5.2. Disposition du deuxième écran​

1- Branchez un deuxième écran à l'ordinateur (si ce n'est pas déjà fait).

2- Dans les Paramètres du système, tapez affichage dans la zone de recherche, puis cliquez sur Affichage.

3- Repérez les deux écrans dans la zone de disposition. Glissez l'écran 2 à gauche, puis à droite de l'écran 1.

4- Déplacez la souris jusqu'au bord de l'écran. Vérifiez que le pointeur passe bien sur l'autre écran.

5- Choisissez l'écran principal (celui qui affiche la barre des tâches) avec le bouton Définir comme principal.

6- Essayez les modes Étendre et Dupliquer (miroir). Cliquez sur Appliquer pour confirmer chaque changement.

Question-défi

Quelle est la résolution recommandée de chaque écran ? Pourquoi vaut-il mieux l'utiliser plutôt qu'une résolution plus basse ?

Réponse

La résolution recommandée est la résolution native de l'écran, soit le nombre réel de pixels. Une autre résolution force l'écran à mettre l'image à l'échelle, ce qui rend l'affichage flou.

5.3. Ajouter une disposition de clavier​

1- Dans les Paramètres du système, ouvrez Clavier, cliquez sur l'onglet Dispositions (1), puis sur Ajouter (2).

2- Tapez fran dans la zone de recherche, cliquez sur Français (c'est la disposition de la France, AZERTY), puis sur Ajouter (3). Vous pouvez aussi choisir Anglais (États-Unis).

3- Cliquez sur l'indicateur de clavier ca apparu dans le panneau, près de l'horloge (1). Notez que vous pouvez maintenant basculer d'une disposition à l'autre. Le raccourci Super + Espace permet aussi de basculer.

4- Ouvrez l'Éditeur de texte à partir du menu. Tapez la phrase « Allo, ceci est un test » avec Français (Canada) et appuyez sur Entrée. Basculez vers Français (Super + Espace), puis tapez la phrase de nouveau en appuyant sur les mêmes touches.

Question-défi

Quelles touches sont à un emplacement différent entre Français (Canada) et Français (France) ? Pourquoi existe-t-il plusieurs dispositions de clavier ?

Réponse

Avec Français (France) (AZERTY), les touches A, Z, Q, W et M changent de place. Les accents et les caractères spéciaux sont aussi à d'autres endroits.

Les dispositions existent parce que chaque langue ou région a ses propres caractères et habitudes de frappe. Le matériel (les touches) est le même, c'est le système d'exploitation qui interprète le code de chaque touche.

5- Revenez à Français (Canada) (Super + Espace) et fermez l'éditeur sans enregistrer. Dans Dispositions, cliquez sur Français (1), puis sur Supprimer (2) pour retirer la disposition ajoutée.

5.4. Informations sur le matériel​

Linux Mint offre plusieurs façons de connaître le matériel de l'ordinateur.

1- Dans les Paramètres du système, tapez syst dans la zone de recherche, puis cliquez sur Renseignements sur le système (section Matériel).

2- Ouvrez le menu, tapez hardinfo et appuyez sur Entrée. Explorez les sections Résumé, Processeur, Mémoire et Périphériques de stockage dans la colonne de gauche.

6. Mise à jour du système d'exploitation​

Le système que vous avez installé provient d'un fichier ISO publié il y a plusieurs mois. Depuis ce temps, des correctifs de sécurité et des corrections de bogues ont été publiés. Il est donc important de mettre à jour le système régulièrement, et en particulier après une installation.

1- Cliquez sur le bouton du menu de Linux Mint, en bas à gauche de l'écran.

2- Placez la souris sur la catégorie Administration (1), puis cliquez sur Gestionnaire de mise à jour (2).

3- Si une fenêtre d'accueil apparaît à la première ouverture, lisez-la et cliquez sur Valider (1).

Selon votre installation, deux autres messages peuvent apparaître :

  • Un bandeau propose de passer à un miroir local (un serveur de téléchargement plus près de chez vous). Vous pouvez cliquer sur Non pour le moment.
  • Le gestionnaire indique qu'une nouvelle version du gestionnaire lui-même est disponible. Il doit se mettre à jour avant d'afficher la liste des mises à jour.

4- Cliquez sur Non dans le bandeau du miroir local (1), puis sur Appliquer la mise à jour au centre de la fenêtre.

5- Tapez votre mot de passe, puis cliquez sur S'authentifier (1).

6- Cliquez sur Actualiser (1) pour que le gestionnaire consulte les serveurs de Linux Mint.

7- Attendez la fin de l'actualisation, sans rien toucher.

8- Par défaut, la version actuelle des paquets n'est pas affichée. Ouvrez le menu Affichage, placez la souris sur Colonnes visibles, puis cochez Ancienne version.

9- Observez la liste. Pour chaque mise à jour, notez le nom du paquet, la version actuelle et la nouvelle version.

10- Cliquez sur Installer les mises à jour (1). Mint vous demande de saisir votre mot de passe.

remarque

Si vous venez de saisir votre mot de passe (par exemple pour la mise à jour du gestionnaire), il n'est pas redemandé : l'autorisation reste valide quelques minutes.

Question-défi

Pourquoi le système demande-t-il le mot de passe pour installer des mises à jour alors que vous êtes déjà connecté ?

Réponse

Installer des logiciels modifie le système pour tous les utilisateurs. Cette action nécessite les privilèges d'administrateur. Le mot de passe permet de confirmer que c'est bien un administrateur qui effectue l'opération.

Dans le terminal, on obtient ces privilèges temporaires avec la commande sudo (voir section 3.2).

11- Attendez pendant le téléchargement et l'installation des paquets.

12- À la fin de l'installation, lisez le message en haut de la fenêtre. Si le gestionnaire indique qu'un redémarrage est requis, ne redémarrez pas tout de suite.

Question-défi

Quel type de mise à jour nécessite généralement un redémarrage ?

Réponse

Les mises à jour du noyau Linux (le cœur du système d'exploitation). Le nouveau noyau est utilisé seulement après un redémarrage.

7. Initialiser le disque Kingston​

1- Démarrez l'ordinateur à partir de la clé USB.

2- Sélectionnez WinPEx64_A26.iso dans Ventoy.

3- Lorsque Windows PE est complètement chargé en mémoire, retirez la clé USB.

attention

Windows PE est un système d'exploitation Live. Une fois chargée en mémoire, il n'a plus besoin de son support USB.

Retirer la clé permet d'éviter de l'initialiser par erreur.

4- Tapez les commandes ci-dessous pour initialiser le disque.

diskpart
select disk 0
clean
convert gpt
exit

5- Redémarrez l'ordinateur en tapant la commande shutdown /f /r /t 0

Vous devriez avoir le message No bootable device si le disque est correctement effacé. Que signifie ce message ?

Réponse

Ce message signifie que le BIOS n'a pas trouvé de système d'exploitation sur les unités de stockage internes ou USB.

Dans le cas où il n'y aurait aucun disque interne ou où son port SATA ou M.2 ne serait pas activé dans le BIOS, il est possible d'avoir ce message.
