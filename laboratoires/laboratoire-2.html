Laboratoire de la semaine 2

1. Branchement de l'ordinateur et installation ergonomique​

  1. Installez l'ordinateur Dell Precision Tower 3620 de façon ergonomique.

  2. Utilisez deux écrans.

    • Gauche

      • Il doit être l'écran principal au niveau de l'ergonomie.

      • Il doit être connecté avec le connecteur DVI.

      • Vous avez 2 options avec le matériel disponible. Il faut utiliser le moins de câbles et d'adaptateurs lorsque c'est possible, donc utilisez l'option qui nécessite un seul câble.

    • Droite

      • Il doit être connecté avec le connecteur DisplayPort à VGA.

  3. L'ordinateur doit être en mesure de démarrer. Il est normal d'avoir le message No bootable device. Pourquoi selon vous ?

    Réponse

    L'ordinateur n'a détecté aucun système d'exploitation sur les unités de stockage ou il n'y a aucune unité de stockage.

  4. Demandez à l'enseignant de vérifier votre installation.

    astuce

    Voici les éléments et astuces à retenir.

    • Position du boitier (tour).

      • Avoir un dégagement suffisant pour les câbles et l'aération.
      • Le boitier doit laisser un espace de travail suffisant pour l'utilisateur.
      • Il doit être positionné dans une zone non utilisable par l'utilisateur.

    • Position de l'écran.

      • Pas trop loin ni trop proche de l'utilisateur.
      • Environ une distance de bras.
      • Hauteur des yeux.

    • Clavier et souris.

      • Ils doivent être devant l'écran principal.
      • Ils doivent être branchés derrière l'ordinateur dans un port USB 2.0.

    • Gestion des câbles.

      • Ils doivent être derrière l'écran.
      • N'oubliez pas les attache-câbles.

    • Pour la connexion de l'écran, il est préférable de le connecter directement à l'ordinateur sans adaptateur si c'est possible.

2. Démarrer l'ordinateur avec Ventoy​

Ventoy est un logiciel qui permet d'avoir plusieurs fichiers image démarrables sur une unité de stockage. Vous aurez plus d'information à son sujet au cours de la session.

  1. Éteignez l'ordinateur.

  2. Insérez le disque SSD dans le boitier convertisseur 2.5" à 3.5".

    Rappel

    Pour que la connexion entre le disque SSD et le boitier s'effectue correctement, il ne faut pas insérer le disque SSD verticalement.

  3. Insérez le boitier convertisseur 2.5" à 3.5" dans le tiroir SATA.

  4. Démarrez l'ordinateur.

  5. Dans le menu Ventoy, utilisez les flèches du clavier (↓↑) pour sélectionner Dell_3620_1.vhd. Appuyez sur la touche Entrée pour confirmer votre sélection.

  6. L'ordinateur démarrera dans Windows.

3. Disposition des écrans​

Les écrans doivent être positionnés correctement pour que le mouvement de la souris soit naturel pour passer d'un écran à l'autre.

  1. Effectuez les configurations dans Windows pour que les écrans soient en mode étendu.

    Le positionnement des écrans dans Windows doit représenter la disposition physique. La souris doit se déplacer correctement d'un écran à l'autre.

    Vous devez également indiquer l'écran principal dans la configuration Windows. L'écran principal dans Windows doit être le même qu'au niveau de l'ergonomie.

    astuce

    Pour vous aider, voici les liens vers les procédures.

    • Accédez aux paramètres d'affichage. Procédures -> Windows -> Configuration des écrans -> Accéder aux paramètres d'affichage.

    • Vous devez étendre l'affichage. Lorsque Windows détecte un nouvel écran, il est habituellement déjà configuré en mode étendu. Voici la procédure pour vous aider à comprendre la section Réorganiser vos écrans. Procédures -> Windows -> Configuration des écrans -> Dupliquer et étendre l'affichage.

    • Identifiez le numéro logique des écrans et indiquez l'écran principal. Procédures -> Windows -> Configurations des écrans -> Identifier et sélectionner l'écran.

    • Effectuez le positionnement des écrans. Procédures -> Windows -> Configurations des écrans -> Positionnement.

4. Disposition du clavier​

4.1. Créer un dossier​

Créez sur le bureau un dossier zqmx4.

Il semble y avoir un problème avec les lettres.

Quelle est la raison ? Identifiez la disposition du clavier de l'ordinateur pour comprendre le comportement.

Réponse

La disposition du clavier est ou Français ou Français (France).

Cette disposition utilise un clavier AZERTY, c'est-à-dire que les 5 premières lettres sont : A, Z, E, R, T, Y.

Les dispositions des claviers nord-américains sont QWERTY.

Donc, c'est la disposition du clavier qui est configurée dans l'ordinateur qui détermine le caractère qui doit s'afficher. Le caractère imprimé sur le clavier n'a pas de réelle importance, mais il est préférable d'utiliser un clavier physique identique à la disposition qui est configurée dans l'ordinateur.

4.2. Modification de la disposition​

Veuillez avoir uniquement Français (Canada) et Français - Canada (hérité).

Il faut activer les raccourcis CTRL+ MAJ pour le changement de disposition. Trouvez comment faire dans les procédures des notes de cours.

Avertissement

Plusieurs considèrent que les dispositions Français (Canada) et Français - Canada (hérité) sont identiques.

Ce n'est pas le cas. Il est important de prendre la bonne disposition si une seule des 2 est demandée.

Également, si Windows demande un accès internet, vous n'êtes pas au bon endroit.

5. Nom de l'ordinateur​

Il faut renommer l'ordinateur pour avoir un nom significatif dans le réseau.

Utilisez ce format : LaboTb#.

Il faut remplacer le # par le numéro de votre table. Le numéro est indiqué en rouge au-dessus des tiroirs.

Par exemple, si vous avez la table 9, vous devez nommer l'ordinateur LaboTb9.

Important

Il est important de respecter la nomenclature dans les noms afin d'assurer une norme et une uniformité dans l'entreprise ou l'organisation.

Les majuscules et minuscules doivent être reproduites correctement.

6. Explorateur de fichiers​

6.1. Dossier e24​

Ouvrez le dossier e24 qui se retrouve sur le bureau.

Pourquoi ne le voyez-vous pas ?

Réponse

Le dossier est masqué/caché.

Vous devez activer l'option dans l'Explorateur de fichiers pour afficher les éléments masqués.

Activez l'option nécessaire pour voir le dossier.

6.2. Fichier .txt​

Dans le dossier e24, déterminez le nombre de fichiers dont l'extension se termine par .txt.

Réponse

Il y a 3 fichiers avec une extension .txt (doc1.txt, doc2.txt et doc5.txt).

Il y a 1 fichier dont l'extension est .css (doc3.txt.css) et 1 fichier dont l'extension est .ini (doc4.txt.ini).

Vous devez afficher les extensions de noms de fichiers dans l'Explorateur de fichiers.

Activez l'option nécessaire pour obtenir la réponse.

6.3. Copie du fichier Zip​

  1. Créez le dossier c:\temporaire\.
  2. Copiez le fichier logiciels-1r1.zip qui se retrouve sur la clé USB du laboratoire dans le dossier c:\temporaire\.
  3. Lorsque la copie est terminée, retirez la clé USB proprement.

6.4 Extraction du fichier zip​

  1. Extrayez les fichiers et dossiers contenus dans le fichier c:\temporaire\logiciels-1r1.zip dans le dossier c:\apps\.
astuce

Il n'est pas nécessaire de créer le dossier au préalable. L'utilitaire va le créer lors de l'extraction.

6.5 Accès rapide​

  1. Épinglez le dossier c:\apps\ dans accès rapide de l'Explorateur de fichiers.

6.6. Démarrage de l'Explorateur de fichiers​

Il faut mettre Ce PC et non Accès rapide à l'ouverture de l'Explorateur de fichiers.

Avertissement

La procédure fournie dans les notes de cours fait référence au site de Microsoft.

Est-ce que l'explication est facile à comprendre sur le site de Microsoft ? Pas vraiment. Il arrive parfois que la documentation officielle ne soit pas facilement compréhensible. La procédure pour Windows 10 est mieux expliquée.

Demandez à l'enseignant de vous expliquer la procédure.

7. Gestion des logiciels​

Les logiciels d'installation sont dans le dossier c:\apps\.

7.1. Installation​

Vous devez sélectionner la bonne version du logiciel d'installation.

Rappel

Pour la version 64 bits, le programme contient généralement le suffixe x64.

Pour la version 32 bits, le programme contient le suffixe x86 ou x32.

Navigateur Web

  • Google Chrome
    • ChromeStandaloneSetup??.exe
    • Utilisez le fichier en fonction de l'architecture 64 bits
  • Firefox
    • Firefox Setup 1530.0.4x??.msi
    • Utilisez le fichier en fonction de l'architecture 32 bits

Éditeur de texte

  • NotePad++
    • npp.8.5.5.Installer.x??.exe
    • Utilisez le fichier en fonction de l'architecture 32 bits

Lecteur PDF

  • Sumatra PDF
    • SumatraPDF-3.6.1-??-install.exe
    • Utilisez le fichier en fonction de l'architecture 64 bits

7.2. Programme par défaut​

1- Il faut mettre Chrome comme navigateur par défaut.

2- Il faut mettre Bloc-Notes pour les fichiers .css.

3- Il faut mettre Sumatra pour les fichiers .pdf.

7.3. Désinstallation de logiciels​

1- Désinstallez le logiciel Xbox.

2- Désinstallez le logiciel Microsoft Teams.

8. Alimentation​

8.1. Identification de la configuration​

Identifiez le temps de mise en veille de l'ordinateur et de l'écran qui est actuellement configuré dans Windows.

Réponse

L'écran se désactive après 10 minutes.

L'ordinateur se met en veille après 30 minutes.

8.2. Modification de la configuration​

Il faut désactiver les écrans après 30 minutes.

L'ordinateur ne doit jamais se mettre en veille.

Il faut mettre le mode d'alimentation à Performances élevées.

9.4 Questions​

  1. Quel Windows a la version la moins récente ?

    Réponse

    Dell_3620_3.vhdx Version : Windows 11 24H2
    Build : 26100.1742
    Édition : Famille

    La version 24H2 date de la 2e moitié de l'année 2024.

  2. Quel Windows a la version la plus récente ?

    Réponse

    Dell_3620_2.vhdx Version : Windows 11 25H2
    Build : 26200.8457
    Édition : Professionnel

    La version 25H2 date de la 2e moitié de l'année 2025. Dell_3620_1 est également 25H2. Mais il faut regarder le plus grand numéro de build. 26200.8457 est plus grand que 26200.8037.

  3. Quel Windows a l'édition qui offre le plus de fonctionnalités ?

    Réponse

    Dell_3620_2.vhdx Version : Windows 11 25H2
    Build : 26200.8457
    Édition : Professionnel

    L'édition professionnelle offre plus de fonctionnalités que l'édition Famille.

10. Extra​

10.1. Disposition Portrait​

  1. Éteignez l'ordinateur Dell Precision Tower 3620.
  2. Ajoutez un 3e écran.
  3. Positionnez un des écrans en mode portrait et effectuez la configuration dans Windows.
  4. Configurez les deux autres écrans en mode miroir.
  5. Effectuez la configuration dans Windows pour avoir l'écran en mode portrait.

10.2. God Mode​

Les configurations ci-dessous ne sont pas dans les notes de cours. Veuillez faire des recherches pour trouver comment les réaliser.

Créez l'icône pour le God Mode de Windows.

L'information ne se retrouve pas dans les notes de cours. Effectuez une recherche sur le Web.

Indice

Il faut créer un dossier avec un code alphanumérique.

Les configurations ci-dessous se font par le God Mode.

- Modifiez le comportement des boutons d’alimentation. Il faut que l’écran se ferme (Désactiver l’Affichage ou Éteindre l’écran) lorsque le bouton Marche/Arrêt est appuyé.

- Modifiez l’affichage de l’heure pour que le premier jour de la semaine soit mardi.

- Renommez cet ordinateur. Le nom doit être Init1R1. Ce doit être le nom et non la description.
